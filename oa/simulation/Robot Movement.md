# Robot Movement — 指令合法性与传送带连锁移动

> **C1 / Simulation / Robot Movement**  
> 预计用时：**45–60 分钟** ｜ 语言：**C++17/20** ｜ 难度：**中等**  
> 训练重点：读题建模、状态转移、事件连锁、事务边界、边界测试  
> **本文件仅包含完整题目描述、样例和测试要求，不包含参考代码或解法。**

## 1. Problem Statement

给定一个二维地图、一台机器人的初始朝向，以及一串操作指令。

机器人可以原地转向、沿当前朝向前进、沿当前朝向后退。地图存在墙壁和**传送带（Conveyor）**：机器人每次进入传送带格子时，会立即被传送带向箭头方向移动一格；如果新的格子仍是传送带，则继续移动，直到进入普通地面为止。

**请判断整串指令能否全部合法执行。**

- 如果所有指令都合法，输出 `VALID`、机器人的最终坐标与朝向。
- 如果某条指令无法合法完成，输出 `INVALID` 和**第一条失败指令的编号**（从 1 开始）。

**重要：本题采用严格的整串指令合法性规则。** 一次移动途中碰到墙壁或地图边界，就视为该条指令失败，不允许“移动一部分后停止并继续后面的指令”。任意指令失败，整串指令都判定为非法。

## 2. 地图与坐标

地图大小为 `H × W`，行号自上而下、列号自左而右，**均从 1 开始**。

| 字符 | 含义 |
|---|---|
| `.` | 普通地面，可进入 |
| `#` | 墙壁，不可进入 |
| `S` | 机器人初始位置；离开后视为普通地面 |
| `^` | 传送带：向上 |
| `v` | 传送带：向下 |
| `<` | 传送带：向左 |
| `>` | 传送带：向右 |

保证地图中恰好有一个 `S`。机器人只有**位置和朝向**，不会改变墙壁或传送带的布局；地图中也没有其他机器人。

机器人的朝向使用 `N`、`E`、`S`、`W`，依次代表北、东、南、西。

## 3. 指令规则

每条指令单独占一行，有以下四种形式：

| 指令 | 含义 |
|---|---|
| `L` | 原地左转 90° |
| `R` | 原地右转 90° |
| `F k` | 沿当前朝向前进 `k` **次单位移动** |
| `B k` | 沿当前朝向反方向移动 `k` **次单位移动**；朝向不变 |

### 3.1 旋转

- `L`：`N → W → S → E → N`。
- `R`：`N → E → S → W → N`。
- 旋转不改变机器人位置。
- 旋转总是合法。
- 旋转本身不会触发传送带。

### 3.2 单位移动

一次单位移动尝试将机器人移动到相邻的一个格子：

1. 若目标超出地图范围：**失败**。
2. 若目标为墙壁 `#`：**失败**。
3. 否则机器人先进入目标格子。
4. 如果目标是传送带，立即触发下节定义的自动移动连锁过程。
5. 只有整个连锁过程成功结束，当前单位移动才算成功。

### 3.3 传送带（自动移动）

进入传送带格子后，机器人按照格子上的箭头方向**自动移动一格**。

- 自动移动也不能穿墙、越界。
- 若自动移动进入新的传送带，继续按照**新格子的箭头**移动。
- 直到自动移动抵达普通地面 `.` 或初始格 `S` 时，本轮连锁过程才结束。
- 传送带自动移动**不会改变机器人朝向**。
- 如果自动移动需要进入墙壁或越过边界，则当前指令失败。
- 如果自动移动陷入传送带循环，无法到达普通地面，则当前指令失败；程序必须终止，不能无限循环。

**触发规则：只有进入传送带才会发生自动移动。** 不存在静止站在传送带上等待另一条指令的状态：成功的移动连锁必须结束在普通地面。

### 3.4 多步移动 `F k` / `B k`

- 一条 `F k` 或 `B k` 指令包含恰好 `k` 次单位移动。
- **每次**单位移动后，必须先完成可能触发的传送带连锁，才能开始下一次单位移动。
- `B k` 的单位移动方向总是当前朝向的反方向；不会因此转身。
- 如果第 `j` 次单位移动或它产生的传送带连锁失败，则**整条指令失败**，即使前 `j−1` 次单位移动成功。
- 整条指令失败即判定整串指令 `INVALID`，不会继续执行后续指令。

例如机器人面向东执行 `F 3`：

~~~text
第 1 次：向东一格 -> 若进入传送带则完整处理
第 2 次：从上一步落点再次向东一格 -> 若进入传送带则完整处理
第 3 次：同理
~~~

因此，`F 3` **不等于**“直接检查机器人右方第三个格子”。传送带可能改变机器人的中间位置。

## 4. 输入格式

~~~text
H W
grid[1]
grid[2]
...
grid[H]
D
Q
command[1]
command[2]
...
command[Q]
~~~

字段说明：

- `H W`：两个整数，地图行数和列数。
- `grid[i]`：长度恰为 `W` 的字符串。
- `D`：机器人初始朝向，取值 `N/E/S/W`。
- `Q`：指令条数。
- 每个 `command[i]` 为 `L`、`R`、`F k` 或 `B k`。

输入保证格式合法，不需要处理未知指令、缺失参数或非数字 `k`。

## 5. 输出格式

### 全部指令合法

输出一行：

~~~text
VALID row col direction
~~~

其中 `row`、`col` 是从 **1 开始**的最终坐标，`direction` 为 `N/E/S/W`。

### 存在非法指令

输出一行：

~~~text
INVALID i
~~~

其中 `i` 是第一条失败指令的 **1-based** 编号。不要再输出部分完成时的坐标或朝向。

## 6. 数据范围

| 参数 | 约束 |
|---|---|
| `2 ≤ H, W ≤ 30` | 地图大小 |
| `1 ≤ Q ≤ 1,000` | 指令数量 |
| `1 ≤ k ≤ 20` | 单条前进/后退指令的步数 |
| `grid` | 只能使用规定的 7 类字符；恰有一个 `S` |
| 时间限制（练习建议） | 2 秒 |
| 内存限制（练习建议） | 256 MB |

数据可能包含没有边框墙壁的地图，因此**不能假设边界一定是 `#`**。

## 7. 样例

### Sample 1 — 正常移动、传送带、旋转

**Input**

~~~text
5 7
#######
#S..>.#
#.#...#
#.....#
#######
E
4
F 2
F 1
R
F 1
~~~

**Output**

~~~text
VALID 3 6 S
~~~

**Explanation**

- 初始在 `(2, 2)`，面向东。
- `F 2`：移动到 `(2, 4)`。
- `F 1`：进入 `(2, 5)` 的 `>`，立即自动向东到 `(2, 6)`。
- `R`：转为面向南。
- `F 1`：移动到 `(3, 6)`；所有指令合法。

### Sample 2 — 多步指令中途失败（传送带撞墙）

**Input**

~~~text
4 7
#######
#S.>#.#
#.....#
#######
E
2
F 2
R
~~~

**Output**

~~~text
INVALID 1
~~~

**Explanation**

第 1 条指令是 `F 2`。

- 第 1 次单位移动：`(2, 2) → (2, 3)`，合法。
- 第 2 次单位移动：进入 `(2, 4)` 的 `>`。
- 自动尝试进入 `(2, 5)`，但这里是墙壁 `#`。
- 因此第 1 条指令整体失败。不能把 `F 2` 当作 `F 1` 接受。

### Sample 3 — 传送带循环

**Input**

~~~text
6 7
#######
#.....#
#S>v..#
#.^<..#
#.....#
#######
E
1
F 1
~~~

**Output**

~~~text
INVALID 1
~~~

**Explanation**

进入 `(3, 3)` 后，自动移动形成循环：

~~~text
(3,3) > -> (3,4) v -> (4,4) < -> (4,3) ^ -> (3,3) ...
~~~

无法到达普通地面，因此该指令失败。

### Sample 4 — 后退不改变朝向

**Input**

~~~text
5 7
#######
#.....#
#..S..#
#.....#
#######
N
4
B 1
L
F 2
R
~~~

**Output**

~~~text
VALID 4 2 N
~~~

**Explanation**

- 初始 `(3, 4)`，面向北。
- `B 1`：向南后退至 `(4, 4)`，仍面向北。
- `L`：转向西。
- `F 2`：到 `(4, 2)`。
- `R`：转向北。

## 9. OA 训练要求（非题目规则）

建议在编码前，先在纸上或注释中简要回答：

- **State**：哪些数据会随模拟改变？哪些地图信息不可变？
- **Command 与 Event**：输入的一条指令和自动移动是不是同一个概念？
- **Transaction boundary**：单次单位移动、整条 `F k`，还是整串指令？
- **Order**：手动移动、传送带连锁、下一次手动移动的先后关系是什么？
- **Failure**：墙壁、越界、传送带循环，应返回什么结果？
- **Invariant**：每次合法完成一条指令后，机器人可能停在哪些格子？

**建议时间预算**：读题与建模 10–15 分钟；实现 25–30 分钟；样例与边界测试 10–15 分钟。先求完整正确，再考虑优化或抽象。

题目**不要求**使用递归、BFS、Priority Queue 或事务式复制；可以自由选择实现。若希望练习 TEDS，可以参考同目录的《TEDS — Transactional Event-Driven Simulation》——但要保证实现严格遵守本题规则。
