# 系统级 C++ 设计面试题 02：内存与数据结构（6–10）

> C++17 练习版；每题给定可测试的约束。以下代码各题单独编译，按需加入标准头文件（cstdint、cstddef、memory、new、type_traits、utility、stdexcept、vector、list、unordered_map、optional、mutex、atomic、array、functional）。

## 6. 从零实现 Hash Map（P1）

**题目**：不使用 STL 容器实现 uint64_t→uint64_t 哈希表，开放定址 + 线性探测，支持 put/get/erase。固定容量、无自动扩容。要求允许 key=0；删除不能破坏探测链。

~~~cpp
class FixedHashMap {
    enum class State : unsigned char { Empty, Used, Deleted };
    struct Slot {
        uint64_t key = 0, value = 0;
        State state = State::Empty;
    };
    std::unique_ptr<Slot[]> slots_;
    size_t buckets_, count_ = 0;
    static size_t hash(uint64_t x) {
        x ^= x >> 33; x *= 0xff51afd7ed558ccdULL;
        x ^= x >> 33; x *= 0xc4ceb9fe1a85ec53ULL;
        return static_cast<size_t>(x ^ (x >> 33));
    }
public:
    explicit FixedHashMap(size_t buckets)
        : slots_(new Slot[buckets]), buckets_(buckets) {
        if (!buckets) throw std::invalid_argument("buckets");
    }
    bool put(uint64_t key, uint64_t value) {
        size_t firstDeleted = buckets_;
        size_t start = hash(key) % buckets_;
        for (size_t n = 0; n < buckets_; ++n) {
            size_t i = (start + n) % buckets_;
            auto& s = slots_[i];
            if (s.state == State::Used && s.key == key) {
                s.value = value;
                return true;
            }
            if (s.state == State::Deleted && firstDeleted == buckets_)
                firstDeleted = i;
            if (s.state == State::Empty) {
                size_t target = firstDeleted == buckets_ ? i : firstDeleted;
                slots_[target] = {key, value, State::Used};
                ++count_;
                return true;
            }
        }
        if (firstDeleted != buckets_) {
            slots_[firstDeleted] = {key, value, State::Used};
            ++count_;
            return true;
        }
        return false; // completely full
    }
    std::optional<uint64_t> get(uint64_t key) const {
        size_t start = hash(key) % buckets_;
        for (size_t n = 0; n < buckets_; ++n) {
            const auto& s = slots_[(start + n) % buckets_];
            if (s.state == State::Empty) return std::nullopt;
            if (s.state == State::Used && s.key == key) return s.value;
        }
        return std::nullopt;
    }
    bool erase(uint64_t key) {
        size_t start = hash(key) % buckets_;
        for (size_t n = 0; n < buckets_; ++n) {
            auto& s = slots_[(start + n) % buckets_];
            if (s.state == State::Empty) return false;
            if (s.state == State::Used && s.key == key) {
                s.state = State::Deleted;
                --count_;
                return true;
            }
        }
        return false;
    }
    size_t size() const { return count_; }
};
~~~

**复杂度**：期望 O(1) 操作，极端碰撞 O(buckets)；空间 O(buckets)。**面试要点**：tombstone；load factor；删除后探测链；rehash 与引用失效；DoS hash flooding；固定表满了如何通知。以上非线程安全。

## 7. Custom Fixed-Block Allocator（P1）

**题目**：预分配 N 个同尺寸、满足指定 alignment 的块；O(1) allocate/deallocate；用空闲链表复用内存。分配器只管理 raw storage，不负责 C++ 对象构造与析构。

~~~cpp
class FixedBlockAllocator {
    struct FreeNode { FreeNode* next; };
    void* storage_ = nullptr;
    FreeNode* free_ = nullptr;
    size_t stride_, count_, alignment_;
public:
    FixedBlockAllocator(size_t blockSize, size_t n, size_t alignment)
        : stride_(0), count_(n), alignment_(alignment) {
        if (!n || !alignment || (alignment & (alignment - 1)) ||
            alignment < alignof(void*)) throw std::invalid_argument("args");
        if (blockSize > SIZE_MAX - (alignment - 1))
            throw std::overflow_error("stride");
        stride_ = (std::max(blockSize, sizeof(FreeNode)) +
                   alignment - 1) & ~(alignment - 1);
        if (stride_ > SIZE_MAX / n) throw std::overflow_error("size");
        storage_ = ::operator new(stride_ * n, std::align_val_t(alignment_));
        auto* p = static_cast<unsigned char*>(storage_);
        for (size_t i = 0; i < n; ++i) {
            auto* node = reinterpret_cast<FreeNode*>(p + i * stride_);
            node->next = free_;
            free_ = node;
        }
    }
    void* allocate() noexcept {
        if (!free_) return nullptr;
        auto* result = free_;
        free_ = free_->next;
        return result;
    }
    void deallocate(void* p) noexcept {
        if (!p) return;
        // Precondition: p is a currently allocated block from this pool.
        auto* node = reinterpret_cast<FreeNode*>(p);
        node->next = free_;
        free_ = node;
    }
    ~FixedBlockAllocator() {
        ::operator delete(storage_, std::align_val_t(alignment_));
    }
    FixedBlockAllocator(const FixedBlockAllocator&) = delete;
    FixedBlockAllocator& operator=(const FixedBlockAllocator&) = delete;
};
~~~

**复杂度**：allocate/deallocate O(1)，总空间 O(N×stride)。**面试要点**：alignment、越界及整数溢出、double-free/foreign pointer、free list 污染、thread-local pool；这个实例不是线程安全的，也不检查错误释放。块地址稳定，但对象生命周期仍由调用方负责。

## 8. Fixed-Size Object Pool（P1）

**题目**：为类型 T 预留 N 个槽，create(args...) 构造，destroy(T*) 析构并归还；支持不可默认构造类型。要求构造抛异常时空闲槽不丢失。

~~~cpp
template<class T>
class ObjectPool {
    using Storage = std::aligned_storage_t<sizeof(T), alignof(T)>;
    struct Slot {
        Storage data;
        size_t next;
        bool live = false;
    };
    std::unique_ptr<Slot[]> slots_;
    size_t cap_, head_;
public:
    explicit ObjectPool(size_t n)
        : slots_(new Slot[n]), cap_(n), head_(n ? 0 : n) {
        for (size_t i = 0; i < n; ++i)
            slots_[i].next = i + 1;
    }
    template<class... A>
    T* create(A&&... args) {
        if (head_ == cap_) return nullptr;
        size_t id = head_;
        T* p = new (&slots_[id].data) T(std::forward<A>(args)...);
        head_ = slots_[id].next; // after construction succeeds
        slots_[id].live = true;
        return p;
    }
    void destroy(T* p) {
        if (!p) return;
        // Precondition: p points to a live T owned by this pool.
        auto* base = reinterpret_cast<unsigned char*>(slots_.get());
        auto* addr = reinterpret_cast<unsigned char*>(p);
        auto offset = addr - base;
        if (offset < 0 || static_cast<size_t>(offset) % sizeof(Slot))
            throw std::invalid_argument("foreign pointer");
        size_t id = static_cast<size_t>(offset) / sizeof(Slot);
        if (id >= cap_ || !slots_[id].live)
            throw std::invalid_argument("double free/foreign pointer");
        p->~T();
        slots_[id].live = false;
        slots_[id].next = head_;
        head_ = id;
    }
    ~ObjectPool() {
        for (size_t i = 0; i < cap_; ++i)
            if (slots_[i].live)
                reinterpret_cast<T*>(&slots_[i].data)->~T();
    }
};
~~~

**复杂度**：O(1) create/destroy，O(N) 析构；空间 O(N)。**面试要点**：placement new、aligned storage、live bit、异常安全、类型析构 noexcept、跨线程归还；示例 destroy 的指针距离判断只适用于同一 allocation 的有效指针比较，生产版应使用可验证 handle/index 避免对无关指针相减产生 UB。以上假定调用方传入本池返回的指针，且不可并发使用。

## 9. Lock-Free SPSC Ring Buffer（P1）

**题目**：单生产者单消费者、固定容量 N；try_push/try_pop 不阻塞，满/空返回 false；不使用 mutex。假设 T 可 noexcept move，N>=1。

~~~cpp
template<class T, size_t N>
class SpscRing {
    static_assert(N > 0);
    struct alignas(64) AlignedIndex { std::atomic<size_t> v{0}; };
    std::array<std::optional<T>, N> cells_;
    AlignedIndex head_, tail_;
public:
    bool try_push(T value) {
        size_t t = tail_.v.load(std::memory_order_relaxed);
        size_t h = head_.v.load(std::memory_order_acquire);
        if (t - h == N) return false;
        cells_[t % N].emplace(std::move(value));
        tail_.v.store(t + 1, std::memory_order_release);
        return true;
    }
    std::optional<T> try_pop() {
        size_t h = head_.v.load(std::memory_order_relaxed);
        size_t t = tail_.v.load(std::memory_order_acquire);
        if (h == t) return std::nullopt;
        std::optional<T> out(std::move(*cells_[h % N]));
        cells_[h % N].reset();
        head_.v.store(h + 1, std::memory_order_release);
        return out;
    }
};
~~~

**复杂度**：O(1)，空间 O(N)。**面试要点**：release 发布元素 / acquire 读取；slot 复用由反方向同步保护；false sharing；大计数器 wrap-around 前提；SPSC 不可擅自改成 MPSC；try_push 参数按值可能在判断满之前发生构造成本。T 移动 noexcept 是维护结构正确性的简化前提。

## 10. Configurable Eviction Cache（P1）

**题目**：支持 FIFO 和 LRU 两种逐出策略；容量固定。FIFO 的 get 不改变顺序，LRU 的 get 刷新顺序；线程安全采用粗粒度互斥。

~~~cpp
template<class K, class V>
class PolicyCache {
public:
    enum class Policy { FIFO, LRU };
private:
    struct Entry { K key; V value; };
    Policy policy_;
    size_t cap_;
    std::list<Entry> order_;
    std::unordered_map<K, typename std::list<Entry>::iterator> pos_;
    std::mutex m_;
public:
    PolicyCache(size_t cap, Policy p) : policy_(p), cap_(cap) {
        if (!cap) throw std::invalid_argument("cap");
    }
    std::optional<V> get(const K& key) {
        std::lock_guard<std::mutex> lk(m_);
        auto it = pos_.find(key);
        if (it == pos_.end()) return std::nullopt;
        V value = it->second->value;
        if (policy_ == Policy::LRU)
            order_.splice(order_.begin(), order_, it->second);
        return value;
    }
    void put(K key, V value) {
        std::lock_guard<std::mutex> lk(m_);
        auto it = pos_.find(key);
        if (it != pos_.end()) {
            it->second->value = std::move(value);
            if (policy_ == Policy::LRU)
                order_.splice(order_.begin(), order_, it->second);
            return;
        }
        order_.push_front({std::move(key), std::move(value)});
        try { pos_.emplace(order_.front().key, order_.begin()); }
        catch (...) { order_.pop_front(); throw; }
        if (order_.size() > cap_) {
            pos_.erase(order_.back().key);
            order_.pop_back();
        }
    }
};
~~~

**复杂度**：平均 O(1)，O(capacity) 空间。**面试要点**：FIFO/LRU/TTL/LFU/W-TinyLFU 权衡；value mutation exception safety；按内存字节而非 entry 数逐出；锁内 copy 导致尾延迟；cache stampede、single-flight。
