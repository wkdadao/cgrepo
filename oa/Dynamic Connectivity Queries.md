# Dynamic Connectivity Queries（离线动态连通性）

> 自拟 C++17/20 两小时 OA 综合题，**不是已核实的 DRW 真题**。
> 重点：Disjoint Set Union（DSU）、Offline Reverse Processing、删除操作。
> 建议用时：120 分钟。P1。

## 1. 背景与任务

一个交易基础设施网络包含 N 个节点与 M 条初始**无向**连接。每条连接都有稳定的唯一 edgeId，编号为 1..M。

运行中某些连接会永久下线。系统需要在下线事件之间查询：

1. 两个节点是否仍然连通。
2. 当前无向图有多少个连通分量（包含孤立节点）。

这是一道**删除边 + 查询**的静态离线题：程序首先读取所有命令，然后才需要输出查询结果，因此允许以任意内部顺序计算，但最终输出必须保持原查询顺序。

基础题**不包含新增或恢复连接**。这使得它可以用倒序处理将“删除”转化成 DSU 擅长的“添加”。

## 2. 输入格式

~~~text
N M Q
u1 v1
...
uM vM
command1
...
commandQ
~~~

第 i 条输入边的 edgeId 为 i。所有边都是无向的，允许平行边与自环。

命令：

| 命令 | 含义 |
| --- | --- |
| REMOVE edgeId | 永久移除这条边；已移除则无操作 |
| ASK u v | 查询当前 u 和 v 是否连通 |
| COUNT | 查询当前连通分量个数 |

初始时所有 M 条边都处于 active 状态。

## 3. 输出格式

- ASK：YES 或 NO。
- COUNT：当前连通分量数，十进制整数。
- REMOVE：不输出。

查询答案按输入中查询命令出现的先后顺序逐行输出。

路径长度允许为 0，因此 ASK u u 必定为 YES，即使 u 是孤立节点。

## 4. 样例一：重复删除与连通分量

输入：

~~~text
5 4 8
1 2
2 3
3 4
4 5
ASK 1 5
REMOVE 2
ASK 1 5
ASK 1 3
REMOVE 2
REMOVE 4
ASK 4 5
COUNT
~~~

输出：

~~~text
YES
NO
NO
NO
3
~~~

解释：边 2 删除后节点 1 与 3 断开；重复 REMOVE 2 不会再次生效。边 4 删除后剩余三个连通分量 {1,2}、{3,4}、{5}。

## 5. 样例二：平行边与自环

输入：

~~~text
2 3 7
1 2
1 2
1 1
ASK 1 2
REMOVE 1
ASK 1 2
REMOVE 2
ASK 1 2
COUNT
ASK 1 1
~~~

输出：

~~~text
YES
YES
NO
2
YES
~~~

解释：移除一条平行边后，另一条仍然使 1 和 2 连通。自环不减少连通分量数。

## 6. 约束

- 1 <= N <= 200000。
- 0 <= M <= 200000。
- 1 <= Q <= 200000。
- 1 <= edgeId <= M（M=0 时不会出现 REMOVE）。
- 输入合法；不必处理未知命令和越界编号。
- 不要求线程安全；可把所有命令存到内存后统一处理。

## 7. 关键语义与正确性要求

- REMOVE 的目标是**某个 edgeId**，不是“两个端点之间的所有边”。
- 同一条边只会真正删除一次；后续重复 REMOVE 均为无操作。
- 需要能够区分“真正导致状态变化的 REMOVE”和“重复 REMOVE”。倒序时不能因为遇到一个重复删除操作就错误恢复边。
- 连通性是无向的，ASK u v 与 ASK v u 相同。
- 初始图可以有多个连通分量；COUNT 包括没有边的单个节点。

## 8. 复杂度目标

核心方法：离线倒序 + DSU（路径压缩、按大小/秩合并）。

建议的整体复杂度：

~~~text
Time:  O((N + M + Q) * alpha(N))
Space: O(N + M + Q)
~~~

思考步骤（只给策略，不提供完整代码）：

1. 先正向扫描命令，确定处理完全部命令后哪些边仍然 active，并标记每次 REMOVE 是否真正生效。
2. 用最终 active 的边初始化 DSU。
3. 逆序读取命令：对 ASK/COUNT 记录答案；对**真正生效的 REMOVE**执行对应边的 union。
4. 将查询答案反转为原始时间顺序输出。

DSU 不需要支持删除；真正的删除已经在时间反转后变成了添加。

## 9. 加分扩展：通用 ADD / REMOVE（不属于必做）

若改为支持：

~~~text
ADD edgeId u v
REMOVE edgeId
ASK u v
COUNT
~~~

且同一 edgeId 可能反复激活、停用，那么普通倒序 DSU 不再足够。设计一种完整离线算法：

1. 为每条边确定在时间轴上的若干 active 区间。
2. 使用线段树覆盖时间区间。
3. DFS 线段树，在节点内合并相关边；退出节点时回滚 DSU 至进入前状态。
4. 叶节点回答对应时间点的查询。

注意：Rollback DSU 通常不要使用普通路径压缩，否则回滚代价和正确性会更加复杂。使用按大小合并与操作历史栈。

此扩展的典型目标为 O((M+Q) log Q log N) 量级（根据 DSU 合并实现而异），不是基础题的要求。

## 10. 自测清单

- N=1，M=0；全部孤立；全部连通。
- 永不 REMOVE；全部 REMOVE；同一 edgeId 反复 REMOVE。
- 平行边逐条删除；自环；初始存在多个连通分量。
- ASK u u；COUNT 首尾变化；大量重复查询。
- 确认每个查询在“其前面命令均已生效”的状态下回答。
