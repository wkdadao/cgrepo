## 1. Thread-Safe LRU Cache（P0）

**题目**：设计固定容量 LRU，支持多线程 get(key)、put(key,value)，命中时更新最近使用顺序，超过容量逐出最久未访问项。容量大于 0；返回值按值复制；不要求无锁。

**参考答案**（单 mutex 保护哈希表和链表的一致性）：

~~~cpp
template<class K, class V>
class ThreadSafeLRU {
    using Node = std::pair<K, V>;
    size_t cap_;
    std::list<Node> lru_; // front = most recently used
    std::unordered_map<K, typename std::list<Node>::iterator> index_;
    mutable std::mutex m_;
public:
    explicit ThreadSafeLRU(size_t cap) : cap_(cap) {
        if (!cap) throw std::invalid_argument("capacity");
    }
    std::optional<V> get(const K& key) {
        std::lock_guard<std::mutex> lk(m_);
        auto it = index_.find(key);
        if (it == index_.end()) return std::nullopt;
        V copy = it->second->second; // copy before modifying recency
        lru_.splice(lru_.begin(), lru_, it->second);
        return copy;
    }
    void put(K key, V value) {
        std::lock_guard<std::mutex> lk(m_);
        auto it = index_.find(key);
        if (it != index_.end()) {
            // Requires V to have non-throwing swap for strong exception guarantee
            using std::swap;
            swap(it->second->second, value);
            lru_.splice(lru_.begin(), lru_, it->second);
            return;
        }
        lru_.emplace_front(std::move(key), std::move(value));
        try {
            index_.emplace(lru_.front().first, lru_.begin());
        } catch (...) {
            lru_.pop_front();
            throw;
        }
        if (lru_.size() > cap_) {
            index_.erase(lru_.back().first);
            lru_.pop_back();
        }
    }
};
~~~

**复杂度**：期望 O(1) get/put、O(capacity) 空间。**面试要点**：为什么必须同时锁住 map 和 list；list iterator 的稳定性；异常安全；get 返回引用在解锁后会悬空；热 key 形成锁竞争；sharding 可扩展但不再保证全局精确 LRU。put 对已有 key 的强保证以 V 的 swap 不抛异常为前提；hash/equality 抛异常时仍需额外约束。

## 2. Bounded Blocking Queue（P0）

**题目**：实现 MPMC 有界队列，push 满时阻塞，pop 空时阻塞。close 后拒绝新的 push，但继续 drain 已入队元素；所有等待线程须醒来。假设 T 的移动构造 noexcept。

~~~cpp
template<class T>
class BlockingQueue {
    std::mutex m_;
    std::condition_variable notEmpty_, notFull_;
    std::deque<T> q_;
    size_t cap_;
    bool closed_ = false;
public:
    explicit BlockingQueue(size_t cap) : cap_(cap) {
        if (!cap) throw std::invalid_argument("capacity");
    }
    bool push(T value) {
        std::unique_lock<std::mutex> lk(m_);
        notFull_.wait(lk, [&] { return closed_ || q_.size() < cap_; });
        if (closed_) return false;
        q_.push_back(std::move(value));
        lk.unlock();
        notEmpty_.notify_one();
        return true;
    }
    std::optional<T> pop() {
        std::unique_lock<std::mutex> lk(m_);
        notEmpty_.wait(lk, [&] { return closed_ || !q_.empty(); });
        if (q_.empty()) return std::nullopt;
        T value = std::move(q_.front());
        q_.pop_front();
        lk.unlock();
        notFull_.notify_one();
        return value;
    }
    void close() {
        {
            std::lock_guard<std::mutex> lk(m_);
            closed_ = true;
        }
        notEmpty_.notify_all();
        notFull_.notify_all();
    }
};
~~~

**复杂度**：O(1) 摊销每次入队/出队；O(capacity) 空间。**面试要点**：close/drain 语义；谓词处理伪唤醒；notify 在释放锁后；析构时必须先由外部确保所有调用结束。队列类型若允许 T 的移动抛异常，要单独设计 pop 的异常保证。参见仓库现有《有界阻塞队列与任务处理器》。

## 3. Thread Pool + Graceful Shutdown（P0）

**题目**：固定 worker 数，submit 返回 future；shutdown 停止接受新任务，但已提交任务必须执行完毕；任务异常传入 future；禁止 worker 自己析构 pool。

~~~cpp
class SimpleThreadPool {
    std::mutex m_;
    std::condition_variable cv_;
    std::deque<std::function<void()>> jobs_;
    std::vector<std::thread> workers_;
    bool stopping_ = false;
    void worker() {
        for (;;) {
            std::function<void()> job;
            {
                std::unique_lock<std::mutex> lk(m_);
                cv_.wait(lk, [&] { return stopping_ || !jobs_.empty(); });
                if (jobs_.empty() && stopping_) return;
                job = std::move(jobs_.front());
                jobs_.pop_front();
            }
            job(); // packaged_task stores the user exception in future
        }
    }
public:
    explicit SimpleThreadPool(size_t n) {
        if (!n) throw std::invalid_argument("worker count");
        try {
            for (size_t i = 0; i < n; ++i)
                workers_.emplace_back([this] { worker(); });
        } catch (...) {
            shutdown();
            throw;
        }
    }
    template<class F>
    auto submit(F&& fn) -> std::future<std::invoke_result_t<F&>> {
        using R = std::invoke_result_t<F&>;
        auto task = std::make_shared<std::packaged_task<R()>>(std::forward<F>(fn));
        auto result = task->get_future();
        {
            std::lock_guard<std::mutex> lk(m_);
            if (stopping_) throw std::runtime_error("pool closed");
            jobs_.emplace_back([task] { (*task)(); });
        }
        cv_.notify_one();
        return result;
    }
    void shutdown() {
        {
            std::lock_guard<std::mutex> lk(m_);
            stopping_ = true;
        }
        cv_.notify_all();
        for (auto& t : workers_)
            if (t.joinable()) t.join();
    }
    ~SimpleThreadPool() { shutdown(); }
};
~~~

**复杂度**：入队 O(1) 摊销，空间 O(waiting jobs + workers)。**面试要点**：worker 构造中途失败的回收；拒绝晚到任务；无界任务队列可能内存失控；任务内部等待同一个 pool 的 future 可能饥饿死锁；shutdown 不可在本 pool 的 worker 内调用。生产版需限定任务队列容量，并定义 cancel/drop/drain 语义。

## 4. Writer-Preferred Reader–Writer Lock（P1）

**题目**：支持 lock_shared/unlock_shared/lock/unlock；当 writer 正在等待时禁止新 reader 插队（不保证公平）。

~~~cpp
class WriterPreferredRWLock {
    std::mutex m_;
    std::condition_variable cv_;
    size_t readers_ = 0, waitingWriters_ = 0;
    bool writerActive_ = false;
public:
    void lock_shared() {
        std::unique_lock<std::mutex> lk(m_);
        cv_.wait(lk, [&] {
            return !writerActive_ && waitingWriters_ == 0;
        });
        ++readers_;
    }
    void unlock_shared() {
        std::lock_guard<std::mutex> lk(m_);
        --readers_; // precondition: calling thread holds shared lock
        if (readers_ == 0) cv_.notify_all();
    }
    void lock() {
        std::unique_lock<std::mutex> lk(m_);
        ++waitingWriters_;
        cv_.wait(lk, [&] { return !writerActive_ && readers_ == 0; });
        --waitingWriters_;
        writerActive_ = true;
    }
    void unlock() {
        std::lock_guard<std::mutex> lk(m_);
        writerActive_ = false;
        cv_.notify_all();
    }
};
~~~

**复杂度**：状态更新 O(1)。**面试要点**：writer-preferred 会饿死 reader；unlock 前提需要 API 使用者遵守；无 reentrancy/upgrade；为什么 waitingWriters 必须包含等待中的 writer；与 std::shared_mutex 比较。

## 5. Work-Stealing Task Scheduler（P1）

**题目**：每个 worker 一个 deque；本地优先取任务，空闲 worker 从其他队列窃取；停止时 drain 已提交任务。下面是学习版：任务默认轮询分配，队列均由 mutex 保护，非 Chase–Lev lock-free 版本。

~~~cpp
class WorkStealingPool {
    struct Queue {
        std::mutex m;
        std::deque<std::function<void()>> jobs;
    };
    std::vector<std::unique_ptr<Queue>> queues_;
    std::vector<std::thread> threads_;
    std::mutex sleepMutex_;
    std::condition_variable wake_;
    std::atomic<size_t> pending_{0}, next_{0};
    std::atomic<bool> stopping_{false};

    bool take(size_t id, std::function<void()>& job) {
        for (size_t k = 0; k < queues_.size(); ++k) {
            size_t idx = (id + k) % queues_.size();
            auto& q = *queues_[idx];
            std::lock_guard<std::mutex> lk(q.m);
            if (q.jobs.empty()) continue;
            if (idx == id) {
                job = std::move(q.jobs.back());
                q.jobs.pop_back();
            } else {
                job = std::move(q.jobs.front());
                q.jobs.pop_front();
            }
            return true;
        }
        return false;
    }
    void run(size_t id) {
        for (;;) {
            std::function<void()> job;
            if (take(id, job)) {
                try { job(); } catch (...) { /* report in production */ }
                pending_.fetch_sub(1, std::memory_order_acq_rel);
                wake_.notify_all();
                continue;
            }
            if (stopping_.load() && pending_.load() == 0) return;
            std::unique_lock<std::mutex> lk(sleepMutex_);
            wake_.wait_for(lk, std::chrono::milliseconds(2));
        }
    }
public:
    explicit WorkStealingPool(size_t n) {
        if (!n) throw std::invalid_argument("workers");
        for (size_t i = 0; i < n; ++i)
            queues_.push_back(std::make_unique<Queue>());
        try {
            for (size_t i = 0; i < n; ++i)
                threads_.emplace_back([this, i] { run(i); });
        } catch (...) { shutdown(); throw; }
    }
    bool submit(std::function<void()> job) {
        // Serialize acceptance with shutdown; simplified via sleepMutex_.
        std::lock_guard<std::mutex> accept(sleepMutex_);
        if (stopping_.load()) return false;
        size_t id = next_.fetch_add(1) % queues_.size();
        {
            std::lock_guard<std::mutex> lk(queues_[id]->m);
            queues_[id]->jobs.push_back(std::move(job));
            pending_.fetch_add(1);
        }
        wake_.notify_one();
        return true;
    }
    void shutdown() {
        {
            std::lock_guard<std::mutex> lk(sleepMutex_);
            stopping_.store(true);
        }
        wake_.notify_all();
        for (auto& t : threads_) if (t.joinable()) t.join();
    }
    ~WorkStealingPool() { shutdown(); }
};
~~~

**复杂度**：取任务最坏 O(number of workers)，每队列操作摊销 O(1)。**面试要点**：本地 LIFO、steal FIFO；提交和 shutdown 的同步；任务完成计数与可见性；sleep/wakeup 策略；单队列热点、false sharing；生产级 Chase–Lev deque 的 owner/thief 内存序和 reclamation。学习版 wait_for 轮询，属于性能妥协。

---
**通用验收**：多线程随机提交/关闭、TSan、线程构造失败、异常注入、shutdown 重入、所有 waiter 是否可结束；Latency 测试分别报告 p50/p99 与吞吐，不将“无锁”等同于更快。

## 6. 从零实现 Hash Map（P1）

**题目**：不使用 STL 容器实现 uint64_t→uint64_t 哈希表，开放定址 + 线性探测，支持 put/get/erase。固定容量、无自动扩容。要求允许 key=0；删除不能破坏探测链。

~~~cpp
class FixedHashMap {
    enum class State : unsigned char { Empty, Used, Deleted };
    struct Slot {
        uint64_t key = 0, value = 0;
        State state = State::Empty;
    };
    std::unique_ptr<Slot[]> slots_;
    size_t buckets_, count_ = 0;
    static size_t hash(uint64_t x) {
        x ^= x >> 33; x *= 0xff51afd7ed558ccdULL;
        x ^= x >> 33; x *= 0xc4ceb9fe1a85ec53ULL;
        return static_cast<size_t>(x ^ (x >> 33));
    }
public:
    explicit FixedHashMap(size_t buckets)
        : slots_(new Slot[buckets]), buckets_(buckets) {
        if (!buckets) throw std::invalid_argument("buckets");
    }
    bool put(uint64_t key, uint64_t value) {
        size_t firstDeleted = buckets_;
        size_t start = hash(key) % buckets_;
        for (size_t n = 0; n < buckets_; ++n) {
            size_t i = (start + n) % buckets_;
            auto& s = slots_[i];
            if (s.state == State::Used && s.key == key) {
                s.value = value;
                return true;
            }
            if (s.state == State::Deleted && firstDeleted == buckets_)
                firstDeleted = i;
            if (s.state == State::Empty) {
                size_t target = firstDeleted == buckets_ ? i : firstDeleted;
                slots_[target] = {key, value, State::Used};
                ++count_;
                return true;
            }
        }
        if (firstDeleted != buckets_) {
            slots_[firstDeleted] = {key, value, State::Used};
            ++count_;
            return true;
        }
        return false; // completely full
    }
    std::optional<uint64_t> get(uint64_t key) const {
        size_t start = hash(key) % buckets_;
        for (size_t n = 0; n < buckets_; ++n) {
            const auto& s = slots_[(start + n) % buckets_];
            if (s.state == State::Empty) return std::nullopt;
            if (s.state == State::Used && s.key == key) return s.value;
        }
        return std::nullopt;
    }
    bool erase(uint64_t key) {
        size_t start = hash(key) % buckets_;
        for (size_t n = 0; n < buckets_; ++n) {
            auto& s = slots_[(start + n) % buckets_];
            if (s.state == State::Empty) return false;
            if (s.state == State::Used && s.key == key) {
                s.state = State::Deleted;
                --count_;
                return true;
            }
        }
        return false;
    }
    size_t size() const { return count_; }
};
~~~

**复杂度**：期望 O(1) 操作，极端碰撞 O(buckets)；空间 O(buckets)。**面试要点**：tombstone；load factor；删除后探测链；rehash 与引用失效；DoS hash flooding；固定表满了如何通知。以上非线程安全。

## 7. Custom Fixed-Block Allocator（P1）

**题目**：预分配 N 个同尺寸、满足指定 alignment 的块；O(1) allocate/deallocate；用空闲链表复用内存。分配器只管理 raw storage，不负责 C++ 对象构造与析构。

~~~cpp
class FixedBlockAllocator {
    struct FreeNode { FreeNode* next; };
    void* storage_ = nullptr;
    FreeNode* free_ = nullptr;
    size_t stride_, count_, alignment_;
public:
    FixedBlockAllocator(size_t blockSize, size_t n, size_t alignment)
        : stride_(0), count_(n), alignment_(alignment) {
        if (!n || !alignment || (alignment & (alignment - 1)) ||
            alignment < alignof(void*)) throw std::invalid_argument("args");
        if (blockSize > SIZE_MAX - (alignment - 1))
            throw std::overflow_error("stride");
        stride_ = (std::max(blockSize, sizeof(FreeNode)) +
                   alignment - 1) & ~(alignment - 1);
        if (stride_ > SIZE_MAX / n) throw std::overflow_error("size");
        storage_ = ::operator new(stride_ * n, std::align_val_t(alignment_));
        auto* p = static_cast<unsigned char*>(storage_);
        for (size_t i = 0; i < n; ++i) {
            auto* node = reinterpret_cast<FreeNode*>(p + i * stride_);
            node->next = free_;
            free_ = node;
        }
    }
    void* allocate() noexcept {
        if (!free_) return nullptr;
        auto* result = free_;
        free_ = free_->next;
        return result;
    }
    void deallocate(void* p) noexcept {
        if (!p) return;
        // Precondition: p is a currently allocated block from this pool.
        auto* node = reinterpret_cast<FreeNode*>(p);
        node->next = free_;
        free_ = node;
    }
    ~FixedBlockAllocator() {
        ::operator delete(storage_, std::align_val_t(alignment_));
    }
    FixedBlockAllocator(const FixedBlockAllocator&) = delete;
    FixedBlockAllocator& operator=(const FixedBlockAllocator&) = delete;
};
~~~

**复杂度**：allocate/deallocate O(1)，总空间 O(N×stride)。**面试要点**：alignment、越界及整数溢出、double-free/foreign pointer、free list 污染、thread-local pool；这个实例不是线程安全的，也不检查错误释放。块地址稳定，但对象生命周期仍由调用方负责。

## 8. Fixed-Size Object Pool（P1）

**题目**：为类型 T 预留 N 个槽，create(args...) 构造，destroy(handle) 析构并归还；支持不可默认构造类型。要求构造抛异常时空闲槽不丢失。

~~~cpp
template<class T>
class ObjectPool {
    using Storage = std::aligned_storage_t<sizeof(T), alignof(T)>;
    struct Slot {
        Storage data;
        size_t next = 0, generation = 0;
        bool live = false;
    };
    std::unique_ptr<Slot[]> slots_;
    size_t cap_, head_;
public:
    struct Handle { size_t index, generation; T* ptr; };
    explicit ObjectPool(size_t n)
        : slots_(new Slot[n]), cap_(n), head_(n ? 0 : n) {
        for (size_t i = 0; i < n; ++i) slots_[i].next = i + 1;
    }
    template<class... A>
    std::optional<Handle> create(A&&... args) {
        if (head_ == cap_) return std::nullopt;
        size_t id = head_;
        T* p = new (&slots_[id].data) T(std::forward<A>(args)...);
        head_ = slots_[id].next; // commit only after constructor succeeds
        slots_[id].live = true;
        return Handle{id, slots_[id].generation, p};
    }
    void destroy(Handle h) {
        if (h.index >= cap_) throw std::invalid_argument("bad handle");
        Slot& s = slots_[h.index];
        if (!s.live || s.generation != h.generation ||
            h.ptr != std::launder(reinterpret_cast<T*>(&s.data)))
            throw std::invalid_argument("stale/foreign handle");
        h.ptr->~T(); // T destructor is required noexcept
        s.live = false;
        ++s.generation; // assume generation never wraps
        s.next = head_;
        head_ = h.index;
    }
    ~ObjectPool() {
        // Preconditions: no external threads using the pool/objects.
        for (size_t i = 0; i < cap_; ++i)
            if (slots_[i].live)
                std::launder(reinterpret_cast<T*>(&slots_[i].data))->~T();
    }
};
~~~

**复杂度**：O(1) create/destroy，O(N) 析构；空间 O(N)。**面试要点**：placement new、aligned storage、live bit、异常安全、类型析构 noexcept、跨线程归还；采用 index+generation handle 避免无关指针相减的 UB，并检测 stale handle。对象指针不得在 destroy 后继续使用。以上为非并发对象池。

## 9. Lock-Free SPSC Ring Buffer（P1）

**题目**：单生产者单消费者、固定容量 N；try_push/try_pop 不阻塞，满/空返回 false；不使用 mutex。假设 T 可 noexcept move，N>=1。

~~~cpp
template<class T, size_t N>
class SpscRing {
    static_assert(N > 0);
    struct alignas(64) AlignedIndex { std::atomic<size_t> v{0}; };
    std::array<std::optional<T>, N> cells_;
    AlignedIndex head_, tail_;
public:
    bool try_push(T value) {
        size_t t = tail_.v.load(std::memory_order_relaxed);
        size_t h = head_.v.load(std::memory_order_acquire);
        if (t - h == N) return false;
        cells_[t % N].emplace(std::move(value));
        tail_.v.store(t + 1, std::memory_order_release);
        return true;
    }
    std::optional<T> try_pop() {
        size_t h = head_.v.load(std::memory_order_relaxed);
        size_t t = tail_.v.load(std::memory_order_acquire);
        if (h == t) return std::nullopt;
        std::optional<T> out(std::move(*cells_[h % N]));
        cells_[h % N].reset();
        head_.v.store(h + 1, std::memory_order_release);
        return out;
    }
};
~~~

**复杂度**：O(1)，空间 O(N)。**面试要点**：release 发布元素 / acquire 读取；slot 复用由反方向同步保护；false sharing；大计数器 wrap-around 前提；SPSC 不可擅自改成 MPSC；try_push 参数按值可能在判断满之前发生构造成本。T 移动 noexcept 是维护结构正确性的简化前提。

## 10. Configurable Eviction Cache（P1）

**题目**：支持 FIFO 和 LRU 两种逐出策略；容量固定。FIFO 的 get 不改变顺序，LRU 的 get 刷新顺序；线程安全采用粗粒度互斥。

~~~cpp
template<class K, class V>
class PolicyCache {
public:
    enum class Policy { FIFO, LRU };
private:
    struct Entry { K key; V value; };
    Policy policy_;
    size_t cap_;
    std::list<Entry> order_;
    std::unordered_map<K, typename std::list<Entry>::iterator> pos_;
    std::mutex m_;
public:
    PolicyCache(size_t cap, Policy p) : policy_(p), cap_(cap) {
        if (!cap) throw std::invalid_argument("cap");
    }
    std::optional<V> get(const K& key) {
        std::lock_guard<std::mutex> lk(m_);
        auto it = pos_.find(key);
        if (it == pos_.end()) return std::nullopt;
        V value = it->second->value;
        if (policy_ == Policy::LRU)
            order_.splice(order_.begin(), order_, it->second);
        return value;
    }
    void put(K key, V value) {
        std::lock_guard<std::mutex> lk(m_);
        auto it = pos_.find(key);
        if (it != pos_.end()) {
            it->second->value = std::move(value);
            if (policy_ == Policy::LRU)
                order_.splice(order_.begin(), order_, it->second);
            return;
        }
        order_.push_front({std::move(key), std::move(value)});
        try { pos_.emplace(order_.front().key, order_.begin()); }
        catch (...) { order_.pop_front(); throw; }
        if (order_.size() > cap_) {
            pos_.erase(order_.back().key);
            order_.pop_back();
        }
    }
};
~~~

**复杂度**：平均 O(1)，O(capacity) 空间。**面试要点**：FIFO/LRU/TTL/LFU/W-TinyLFU 权衡；value mutation exception safety；按内存字节而非 entry 数逐出；锁内 copy 导致尾延迟；cache stampede、single-flight。

---
**建议测试**：ASan/UBSan，alignment 用 alignas(64/128) 类型验证，capacity=0、full、tombstone、异常构造与对象析构计数、重复释放、随机序列对照 std::unordered_map。

# 系统级 C++ 设计面试题 03：操作系统与系统编程（11–15）

> 平台：Linux/POSIX + C++17。系统调用可能被信号中断；以下均为可讨论、可扩展的最小核心实现，而不是覆盖安全、日志轮转、权限和守护进程运维的完整产品。

## 11. Asynchronous Logger（P1）

**题目**：多线程 log(text) 快速入队，专用后台线程负责输出；限定队列容量，队列满时显式 drop，关闭时 flush 已接收消息；统计 drop 数。假定输出流寿命覆盖 logger。

~~~cpp
#include <atomic>
#include <condition_variable>
#include <deque>
#include <mutex>
#include <ostream>
#include <string>
#include <thread>

class AsyncLogger {
    std::mutex m_;
    std::condition_variable cv_, drained_;
    std::deque<std::string> q_;
    std::thread worker_;
    std::ostream& out_;
    size_t cap_;
    bool closed_ = false, writing_ = false;
    std::atomic<uint64_t> drops_{0};
    void run() {
        for (;;) {
            std::string line;
            {
                std::unique_lock<std::mutex> lk(m_);
                cv_.wait(lk, [&] { return closed_ || !q_.empty(); });
                if (q_.empty() && closed_) break;
                line = std::move(q_.front());
                q_.pop_front();
                writing_ = true;
            }
            try { out_ << line << '\n'; }
            catch (...) { /* production: report I/O failure */ }
            {
                std::lock_guard<std::mutex> lk(m_);
                writing_ = false;
                if (q_.empty()) drained_.notify_all();
            }
        }
        out_.flush();
    }
public:
    AsyncLogger(std::ostream& out, size_t cap) : out_(out), cap_(cap) {
        if (!cap_) throw std::invalid_argument("capacity");
        worker_ = std::thread([this] { run(); });
    }
    bool log(std::string s) {
        std::lock_guard<std::mutex> lk(m_);
        if (closed_) return false;
        if (q_.size() >= cap_) { drops_.fetch_add(1); return false; }
        q_.push_back(std::move(s));
        cv_.notify_one();
        return true;
    }
    void flush() {
        std::unique_lock<std::mutex> lk(m_);
        drained_.wait(lk, [&] { return q_.empty() && !writing_; });
        lk.unlock();
        out_.flush(); // concurrent direct ostream writes are not supported
    }
    uint64_t dropped() const { return drops_.load(); }
    void shutdown() {
        {
            std::lock_guard<std::mutex> lk(m_);
            closed_ = true;
        }
        cv_.notify_all();
        if (worker_.joinable()) worker_.join();
    }
    ~AsyncLogger() { shutdown(); }
};
~~~

**复杂度**：log 摊销 O(length)，队列内存 O(capacity×average message size)。**面试要点**：drop/block/overwrite 策略；日志排序语义；batching；tail latency；落盘同步 vs ostream flush；输出失败状态；flush 与 worker 的并发写需单线程协议（上例只保证队列 drain，严格 disk durability 不保证）。

## 12. Event-Driven I/O with epoll（P1）

**题目**：用 epoll ET 模式监听多 socket 的可读事件，必须读到 EAGAIN。允许注册/删除 fd，处理对端关闭。用 Linux-only 代码。

~~~cpp
#include <sys/epoll.h>
#include <unistd.h>
#include <fcntl.h>
#include <cerrno>
#include <stdexcept>
#include <array>

class EpollReadLoop {
    int ep_ = ::epoll_create1(EPOLL_CLOEXEC);
public:
    EpollReadLoop() {
        if (ep_ < 0) throw std::runtime_error("epoll_create1");
    }
    ~EpollReadLoop() { ::close(ep_); }
    void add(int fd) {
        int flags = ::fcntl(fd, F_GETFL, 0);
        if (flags < 0 || ::fcntl(fd, F_SETFL, flags | O_NONBLOCK) < 0)
            throw std::runtime_error("fcntl");
        epoll_event ev{};
        ev.events = EPOLLIN | EPOLLET | EPOLLRDHUP;
        ev.data.fd = fd;
        if (::epoll_ctl(ep_, EPOLL_CTL_ADD, fd, &ev) < 0)
            throw std::runtime_error("epoll_ctl");
    }
    void remove(int fd) {
        ::epoll_ctl(ep_, EPOLL_CTL_DEL, fd, nullptr);
        ::close(fd);
    }
    template<class OnBytes>
    void once(OnBytes onBytes, int timeoutMs = 100) {
        std::array<epoll_event, 64> events{};
        int n = ::epoll_wait(ep_, events.data(), events.size(), timeoutMs);
        if (n < 0) {
            if (errno == EINTR) return;
            throw std::runtime_error("epoll_wait");
        }
        for (int i = 0; i < n; ++i) {
            int fd = events[i].data.fd;
            bool closeFd = (events[i].events & (EPOLLERR | EPOLLHUP));
            for (;;) {
                char buf[4096];
                ssize_t r = ::read(fd, buf, sizeof(buf));
                if (r > 0) { onBytes(fd, buf, static_cast<size_t>(r)); continue; }
                if (r == 0) { closeFd = true; break; }
                if (errno == EINTR) continue;
                if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                closeFd = true; break;
            }
            if (closeFd) remove(fd);
        }
    }
};
~~~

**复杂度**：事件驱动 O(ready fds + bytes)，注册 O(1) 摊销内核成本。**面试要点**：ET/LT；ET 不读到 EAGAIN 会卡住；partial read/write；EPOLLOUT 不能长期无条件注册；fd reuse/stale events，实际服务器应使用 generation + stable connection token，不能只用 fd 作为身份；回调不可在自身关闭 fd 后继续使用它。

## 13. Shared-Memory IPC / SPSC（P1）

**题目**：两个 Linux 进程共享固定记录 ring buffer；单 writer、单 reader；共享段由独立初始化步骤先建好；每次传 64-bit value。用 shm_open/ftruncate/mmap；读写用原子同步。

~~~cpp
#include <atomic>
#include <cstdint>
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <stdexcept>

struct alignas(64) SharedCounterRing {
    static constexpr uint64_t CAP = 1024;
    alignas(64) std::atomic<uint64_t> head{0};
    alignas(64) std::atomic<uint64_t> tail{0};
    alignas(64) uint64_t slots[CAP]{};

    bool push(uint64_t value) {
        auto t = tail.load(std::memory_order_relaxed);
        auto h = head.load(std::memory_order_acquire);
        if (t - h == CAP) return false;
        slots[t % CAP] = value;
        tail.store(t + 1, std::memory_order_release);
        return true;
    }
    bool pop(uint64_t& value) {
        auto h = head.load(std::memory_order_relaxed);
        auto t = tail.load(std::memory_order_acquire);
        if (t == h) return false;
        value = slots[h % CAP];
        head.store(h + 1, std::memory_order_release);
        return true;
    }
};
// Run once before consumers attach; filename begins with '/'.
inline void initSharedRing(const char* name) {
    int fd = ::shm_open(name, O_CREAT | O_EXCL | O_RDWR, 0600);
    if (fd < 0) throw std::runtime_error("shm_open");
    if (::ftruncate(fd, sizeof(SharedCounterRing)) != 0) {
        ::close(fd); throw std::runtime_error("ftruncate");
    }
    void* p = ::mmap(nullptr, sizeof(SharedCounterRing),
                     PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    ::close(fd);
    if (p == MAP_FAILED) throw std::runtime_error("mmap");
    new (p) SharedCounterRing();
    ::munmap(p, sizeof(SharedCounterRing));
}
// Attach with shm_open(name, O_RDWR), mmap(MAP_SHARED), then use ring->push/pop.
// Each process unmaps on exit; owner calls shm_unlink when all peers are done.
~~~

**复杂度**：O(1) 每条记录；空间 O(CAP)。**面试要点**：跨进程 C++ 原子语义依赖平台/ABI，须验证 lock-free、CPU 可见性；初始化握手（上例不允许初始化与 attach 并发）；crash 后 head/tail 恢复；共享指针不可直接跨进程使用，改用 offset；huge pages、cache line 对齐、NUMA；buffer overflow/backpressure、stale generation。

## 14. Process Supervisor（P2）

**题目**：启动 child process，退出后按退避策略重启；父进程收到停止请求可先 TERM 后 KILL。下面实现简化的单进程 supervisor 循环，stop flag 由外部发出，execv 使用绝对路径。

~~~cpp
#include <atomic>
#include <chrono>
#include <csignal>
#include <stdexcept>
#include <sys/wait.h>
#include <unistd.h>
#include <thread>
#include <algorithm>
#include <cerrno>

class ProcessSupervisor {
    std::atomic<bool> stop_{false};
public:
    void request_stop() noexcept { stop_.store(true); }
    void run(const char* path, char* const argv[]) {
        int backoffMs = 100;
        while (!stop_.load()) {
            pid_t pid = ::fork();
            if (pid < 0) throw std::runtime_error("fork");
            if (pid == 0) { ::execv(path, argv); _exit(127); }
            int status = 0;
            bool stoppingChild = false;
            while (!stop_.load()) {
                pid_t r = ::waitpid(pid, &status, WNOHANG);
                if (r == pid) break;
                if (r < 0 && errno == EINTR) continue;
                if (r < 0) throw std::runtime_error("waitpid");
                std::this_thread::sleep_for(std::chrono::milliseconds(50));
            }
            if (stop_.load()) {
                if (::kill(pid, SIGTERM) == 0) stoppingChild = true;
                for (int i = 0; i < 20; ++i) {
                    if (::waitpid(pid, &status, WNOHANG) == pid) {
                        stoppingChild = false; break;
                    }
                    std::this_thread::sleep_for(std::chrono::milliseconds(50));
                }
                if (stoppingChild) {
                    ::kill(pid, SIGKILL);
                    while (::waitpid(pid, &status, 0) < 0 && errno == EINTR) {}
                }
                break;
            }
            std::this_thread::sleep_for(std::chrono::milliseconds(backoffMs));
            backoffMs = std::min(backoffMs * 2, 5000);
        }
    }
};
~~~

**复杂度**：监控 O(1) 周期轮询；**面试要点**：上例有外部信号 race：child 恰好已结束、PID 被重用时 kill 风险，生产版用 pidfd；子进程群清理、zombie、TERM timeout、crash loop、stable uptime 重置 backoff、环境变量、身份权限、健康检测。安全的跨进程监控不只靠 waitpid。

## 15. RAII Resource Manager for FDs（P1）

**题目**：给 sockets/files/epoll fd 统一所有权语义；禁止复制、支持移动，确保异常或 early return 自动释放。调用方不能同时拥有同一 fd。

~~~cpp
#include <unistd.h>
#include <utility>

class UniqueFd {
    int fd_ = -1;
public:
    explicit UniqueFd(int fd = -1) noexcept : fd_(fd) {}
    ~UniqueFd() { reset(); }
    UniqueFd(const UniqueFd&) = delete;
    UniqueFd& operator=(const UniqueFd&) = delete;
    UniqueFd(UniqueFd&& rhs) noexcept : fd_(rhs.release()) {}
    UniqueFd& operator=(UniqueFd&& rhs) noexcept {
        if (this != &rhs) reset(rhs.release());
        return *this;
    }
    int get() const noexcept { return fd_; }
    explicit operator bool() const noexcept { return fd_ >= 0; }
    int release() noexcept { return std::exchange(fd_, -1); }
    void reset(int next = -1) noexcept {
        int old = std::exchange(fd_, next);
        if (old >= 0) ::close(old); // never retry close on Linux EINTR
    }
};
~~~

# 系统级 C++ 设计面试题 04：性能与可靠性（16–20）

## 16. High-Throughput Metrics Collection（P1）

**题目**：N 个固定工作线程计数，避免每个事件都更新同一个原子变量；允许读侧读到近似实时 snapshot。每个 worker 只有自己的独占 shard。

~~~cpp
#include <array>
#include <atomic>
#include <cstdint>

template<size_t N>
class ShardedCounters {
    struct alignas(64) Counter { std::atomic<uint64_t> value{0}; };
    std::array<Counter, N> shards_{};
public:
    void increment(size_t workerId, uint64_t n = 1) noexcept {
        // Precondition: workerId < N; one writer per shard.
        shards_[workerId].value.fetch_add(n, std::memory_order_relaxed);
    }
    uint64_t snapshot() const noexcept {
        uint64_t sum = 0;
        for (auto& shard : shards_)
            sum += shard.value.load(std::memory_order_relaxed);
        return sum;
    }
};
~~~

**复杂度**：increment O(1)，snapshot O(N)，O(N×cache line) 空间。**面试要点**：relaxed 足以保证原子计数但不保证同其他字段的一致快照；snapshot 不保证同时刻精确值；thread-local + periodic aggregation、histogram、HDR/t-digest、dynamic worker registration、overflow、observability 自身对 p99 的影响。

## 17. Timer Scheduler with Cancel/Reschedule（P0）

**题目**：单后台线程执行到期回调；支持 schedule(deadline, task)、cancel(id)、reschedule(id,newDeadline)、shutdown。调用后未开始的任务可取消；已开始执行的任务不能回滚。使用稳态时钟；任务 id 单调递增。

~~~cpp
#include <chrono>
#include <condition_variable>
#include <cstdint>
#include <functional>
#include <mutex>
#include <queue>
#include <thread>
#include <unordered_map>

class TimerScheduler {
public:
    using Clock = std::chrono::steady_clock;
    using Task = std::function<void()>;
    using Id = uint64_t;
private:
    struct Entry {
        Clock::time_point when;
        Id id;
        uint64_t ver;
        bool operator>(const Entry& r) const { return when > r.when; }
    };
    struct Info { uint64_t ver; Task task; };
    std::mutex m_;
    std::condition_variable cv_;
    std::priority_queue<Entry, std::vector<Entry>, std::greater<Entry>> heap_;
    std::unordered_map<Id, Info> live_;
    std::thread worker_;
    Id next_ = 1;
    bool stop_ = false;
    void run() {
        std::unique_lock<std::mutex> lk(m_);
        for (;;) {
            if (stop_) return;
            if (heap_.empty()) { cv_.wait(lk); continue; }
            auto top = heap_.top();
            if (Clock::now() < top.when) {
                // No predicate: an earlier timer or reschedule must wake us.
                cv_.wait_until(lk, top.when);
                continue;
            }
            heap_.pop();
            auto it = live_.find(top.id);
            if (it == live_.end() || it->second.ver != top.ver) continue;
            Task task = std::move(it->second.task);
            live_.erase(it); // commit execution / cancel race under same mutex
            lk.unlock();
            try { task(); } catch (...) { /* report in real engine */ }
            lk.lock();
        }
    }
public:
    TimerScheduler() : worker_([this] { run(); }) {}
    Id schedule(Clock::time_point when, Task task) {
        std::lock_guard<std::mutex> lk(m_);
        if (stop_) throw std::runtime_error("stopped");
        Id id = next_++; // exercise assumes no uint64 overflow
        live_.emplace(id, Info{0, std::move(task)});
        try { heap_.push({when, id, 0}); }
        catch (...) { live_.erase(id); throw; }
        cv_.notify_one();
        return id;
    }
    bool cancel(Id id) {
        std::lock_guard<std::mutex> lk(m_);
        return !stop_ && live_.erase(id) != 0;
    }
    bool reschedule(Id id, Clock::time_point when) {
        std::lock_guard<std::mutex> lk(m_);
        if (stop_) return false;
        auto it = live_.find(id);
        if (it == live_.end()) return false;
        uint64_t newVer = it->second.ver + 1; // assume no overflow
        heap_.push({when, id, newVer}); // allocate first, then commit version
        it->second.ver = newVer;
        cv_.notify_one();
        return true;
    }
    void shutdown() {
        {
            std::lock_guard<std::mutex> lk(m_);
            stop_ = true;
            live_.clear(); // drops all not-yet-started tasks
        }
        cv_.notify_all();
        if (worker_.joinable()) worker_.join();
    }
    ~TimerScheduler() { shutdown(); }
};
~~~

**复杂度**：schedule/reschedule O(log H)，cancel 期望 O(1)，触发 O(log H)，H 包括 stale entries。**面试要点**：取消 vs 正在执行的线性化点；wait_until 新增更早 deadline 的 wakeup；单 worker 串行执行回调意味着慢任务阻塞其他 timer；lazy deletion 导致 stale heap 不断增长，应定期 rebuild；steady_clock vs system_clock；任务失败传播；shutdown 从 worker 调用会 self-join，必须禁止或专门处理。OOM 时重新调度已失败的 heap push 不改变当前有效 timer。

## 18. Connection Pool with Timeout & Failures（P1）

**题目**：最多 maxConnections 个 TCP 连接；acquire(timeout) 要么返回独占 lease，要么超时；坏连接不能返还池中。建连接可能阻塞或失败，不应持有主 mutex 执行。

~~~cpp
#include <chrono>
#include <condition_variable>
#include <functional>
#include <mutex>
#include <optional>
#include <vector>
#include <unistd.h>

class FdConnectionPool {
    std::mutex m_;
    std::condition_variable cv_;
    std::vector<int> idle_;
    size_t max_, total_ = 0;
    bool closed_ = false;
    std::function<int()> connect_;
    void release(int fd, bool reusable) {
        std::lock_guard<std::mutex> lk(m_);
        if (closed_ || !reusable) {
            ::close(fd);
            --total_;
        } else idle_.push_back(fd);
        cv_.notify_one();
    }
public:
    class Lease {
        FdConnectionPool* owner_ = nullptr;
        int fd_ = -1;
        bool healthy_ = true;
    public:
        Lease(FdConnectionPool* owner, int fd) : owner_(owner), fd_(fd) {}
        Lease(Lease&& o) noexcept
            : owner_(std::exchange(o.owner_, nullptr)), fd_(o.fd_),
              healthy_(o.healthy_) {}
        Lease(const Lease&) = delete;
        Lease& operator=(const Lease&) = delete;
        ~Lease() { if (owner_) owner_->release(fd_, healthy_); }
        int fd() const { return fd_; }
        void mark_bad() { healthy_ = false; }
    };
    FdConnectionPool(size_t max, std::function<int()> connect)
        : max_(max), connect_(std::move(connect)) {
        if (!max_) throw std::invalid_argument("max");
        idle_.reserve(max_); // make lease return allocation-free
    }
    std::optional<Lease> acquire(std::chrono::steady_clock::duration timeout) {
        auto until = std::chrono::steady_clock::now() + timeout;
        std::unique_lock<std::mutex> lk(m_);
        for (;;) {
            if (closed_) return std::nullopt;
            if (!idle_.empty()) {
                int fd = idle_.back();
                idle_.pop_back();
                return std::optional<Lease>(std::in_place, this, fd);
            }
            if (total_ < max_) {
                ++total_; // reserve slot
                lk.unlock();
                int fd = -1;
                try { fd = connect_(); }
                catch (...) {
                    lk.lock(); --total_; cv_.notify_one(); throw;
                }
                lk.lock();
                if (fd < 0 || closed_) {
                    if (fd >= 0) ::close(fd);
                    --total_; cv_.notify_one(); return std::nullopt;
                }
                return std::optional<Lease>(std::in_place, this, fd);
            }
            if (cv_.wait_until(lk, until) == std::cv_status::timeout)
                return std::nullopt;
        }
    }
    void close() {
        std::lock_guard<std::mutex> lk(m_);
        closed_ = true;
        for (int fd : idle_) { ::close(fd); --total_; }
        idle_.clear();
        cv_.notify_all();
    }
    ~FdConnectionPool() { close(); }
};
~~~

**复杂度**：通常 O(1) 取/还，O(maxConnections) idle 关闭。**面试要点**：timeout 只限制等待空闲槽时间，示例 connect_ 自身未受 timeout 约束；acquire 之前需校验陈旧连接；lease 生命周期必须短于 pool；lease 析构不可抛异常，因此构造阶段 reserve(max) 确保归还时无需分配；重连退避、健康探测、半开连接；关闭时活跃 lease 延迟返回。

## 19. Concurrent Rate Limiter（P1）

**题目**：实现按令牌桶算法限流；容量 burst，单位秒填充 rate 个 token，try_acquire(cost) 不阻塞。多线程并发调用保持单桶精确性。

~~~cpp
#include <algorithm>
#include <chrono>
#include <mutex>
#include <stdexcept>

class TokenBucket {
    using Clock = std::chrono::steady_clock;
    std::mutex m_;
    double tokens_, cap_, rate_;
    Clock::time_point updated_ = Clock::now();
public:
    TokenBucket(double capacity, double perSecond)
        : tokens_(capacity), cap_(capacity), rate_(perSecond) {
        if (capacity <= 0 || perSecond <= 0)
            throw std::invalid_argument("limits");
    }
    bool try_acquire(double cost = 1) {
        if (!(cost > 0) || cost > cap_) return false;
        std::lock_guard<std::mutex> lk(m_);
        auto now = Clock::now();
        double elapsed = std::chrono::duration<double>(now - updated_).count();
        tokens_ = std::min(cap_, tokens_ + std::max(0.0, elapsed) * rate_);
        updated_ = now;
        if (tokens_ < cost) return false;
        tokens_ -= cost;
        return true;
    }
};
~~~

**复杂度**：O(1)，空间 O(1)。**面试要点**：burst vs sustained rate；double precision 和整数定点 token；per-user buckets；多机协调；公平性/排队语义；clock monotonic；低延迟路径上 mutex 竞争。

## 20. Producer–Consumer Pipeline with Backpressure（P0）

**题目**：两阶段 pipeline，A 将输入转化为中间结果交给 B；两条队列均有界。输入关闭后 A drain 并关闭下一阶段，B drain 后退出。处理失败采用 fail-fast 策略。复用本系列第 2 题 BlockingQueue<T>。

~~~cpp
// Requires BlockingQueue<int> implementation from problem #2.
#include <atomic>
#include <thread>
class TwoStagePipeline {
    BlockingQueue<int> input_{128}, intermediate_{128};
    std::thread stageA_, stageB_;
    std::atomic<bool> failed_{false};
public:
    explicit TwoStagePipeline(std::function<void(int)> sink) {
        stageA_ = std::thread([this] {
            try {
                while (auto x = input_.pop()) {
                    if (!intermediate_.push(*x * 2)) break;
                }
            } catch (...) { failed_ = true; input_.close(); }
            intermediate_.close();
        });
        try {
            stageB_ = std::thread([this, sink = std::move(sink)] {
                try {
                    while (auto y = intermediate_.pop()) sink(*y);
                } catch (...) {
                    failed_ = true;
                    input_.close();
                    intermediate_.close();
                }
            });
        } catch (...) {
            input_.close();
            if (stageA_.joinable()) stageA_.join();
            throw;
        }
    }
    bool submit(int value) { return !failed_.load() && input_.push(value); }
    void finish() {
        input_.close();
        if (stageA_.joinable()) stageA_.join();
        if (stageB_.joinable()) stageB_.join();
    }
    bool failed() const { return failed_.load(); }
    ~TwoStagePipeline() { finish(); }
};
~~~

**复杂度**：每个输入 O(1) 排队，加上业务处理时间；最多各 128 元素缓冲。**面试要点**：容量如何决定；阻塞传播链；业务失败是否取消而非 drain；该例 close 后仍 drain，严格 fail-fast 需要 abortable queue（清空+唤醒）；下游调用抛异常后的处理；stop 与 submit 竞态；单 worker 每 stage 保序，多 worker 提升吞吐但引入 reorder。

## 21. Hazard Pointer Memory Reclamation（P1）

**题目**：多 reader 无锁读取不可变 snapshot；单 writer 替换 snapshot 后延迟回收。固定 reader slot，一次一个 reader 占用一个 slot。提供防止读取已释放对象的保护协议。

~~~cpp
#include <array>
#include <atomic>
#include <memory>
#include <stdexcept>
#include <vector>
#include <algorithm>

template<class T, size_t Readers>
class HazardSnapshot {
    std::atomic<T*> current_{nullptr};
    std::array<std::atomic<T*>, Readers> hazards_{};
    std::vector<T*> retired_; // single writer only

    void scan() {
        std::vector<T*> protectedPtrs;
        protectedPtrs.reserve(Readers);
        for (auto& h : hazards_)
            protectedPtrs.push_back(h.load(std::memory_order_seq_cst));
        auto it = retired_.begin();
        while (it != retired_.end()) {
            if (std::find(protectedPtrs.begin(), protectedPtrs.end(), *it)
                == protectedPtrs.end()) {
                delete *it;
                it = retired_.erase(it);
            } else ++it;
        }
    }
public:
    HazardSnapshot() {
        for (auto& h : hazards_) h.store(nullptr);
    }
    // One concurrent reader per readerId, IDs must be in [0, Readers).
    std::optional<T> read(size_t readerId) {
        if (readerId >= Readers) throw std::out_of_range("reader");
        T* p;
        do {
            p = current_.load(std::memory_order_seq_cst);
            hazards_[readerId].store(p, std::memory_order_seq_cst);
        } while (p != current_.load(std::memory_order_seq_cst));
        if (!p) {
            hazards_[readerId].store(nullptr);
            return std::nullopt;
        }
        try {
            T copy = *p; // immutable while published
            hazards_[readerId].store(nullptr, std::memory_order_seq_cst);
            return copy;
        } catch (...) {
            hazards_[readerId].store(nullptr, std::memory_order_seq_cst);
            throw;
        }
    }
    void publish(T replacement) { // single writer
        std::unique_ptr<T> next(new T(std::move(replacement)));
        retired_.reserve(retired_.size() + 1); // allocate before exchange
        T* old = current_.exchange(next.get(), std::memory_order_seq_cst);
        next.release();
        if (old) retired_.push_back(old);
        scan();
    }
    ~HazardSnapshot() {
        // Preconditions: no concurrent readers or publisher.
        delete current_.load();
        for (T* p : retired_) delete p;
    }
};
~~~

**复杂度**：read O(copy(T))，publish 含回收扫描 O(Readers×Retired)（示例采用线性查找，可用哈希降低）；空间与延迟回收数量相关。**面试要点**：必须 protect→validate→dereference；HP vs EBR/QSBR；reader 停住会推迟释放；内存序证明；固定 reader slot 注册；写侧 retire 分配异常保证（本例 reserve 先于 exchange，vector push_back 不应再分配）；值复制的开销。高性能实现不要简单用 seq_cst 代替内存模型分析。

## 22. High-Performance Non-blocking Networking Server（P1）

**题目**：实现小型 Linux 单线程非阻塞 echo reactor。accept/read/write 都处理 EAGAIN 和 EINTR；应为每个连接保留未发送输出，避免短写丢数据。限定每连接待发缓存 1 MiB。

~~~cpp
#include <sys/epoll.h>
#include <sys/socket.h>
#include <fcntl.h>
#include <unistd.h>
#include <cerrno>
#include <array>
#include <string>
#include <unordered_map>
#include <stdexcept>

class EchoReactor {
    struct Conn { std::string pending; size_t sent = 0; };
    int ep_;
    int listener_;
    std::unordered_map<int, Conn> conns_;
    static void nonblocking(int fd) {
        int old = ::fcntl(fd, F_GETFL);
        if (old < 0 || ::fcntl(fd, F_SETFL, old | O_NONBLOCK) < 0)
            throw std::runtime_error("fcntl");
    }
    void interest(int fd, uint32_t flags, int op) {
        epoll_event e{};
        e.data.fd = fd;
        e.events = flags;
        if (::epoll_ctl(ep_, op, fd, &e) != 0)
            throw std::runtime_error("epoll_ctl");
    }
    void closeConn(int fd) {
        ::epoll_ctl(ep_, EPOLL_CTL_DEL, fd, nullptr);
        conns_.erase(fd);
        ::close(fd);
    }
public:
    // caller creates/binds/listens and transfers ownership of listener.
    explicit EchoReactor(int listener) : ep_(::epoll_create1(EPOLL_CLOEXEC)),
                                         listener_(listener) {
        if (ep_ < 0) throw std::runtime_error("epoll_create1");
        nonblocking(listener_);
        interest(listener_, EPOLLIN, EPOLL_CTL_ADD); // LT for simplicity
    }
    ~EchoReactor() {
        for (auto& [fd, conn] : conns_) ::close(fd);
        ::close(listener_);
        ::close(ep_);
    }
    void once() {
        std::array<epoll_event, 64> events{};
        int n = ::epoll_wait(ep_, events.data(), events.size(), 100);
        if (n < 0) {
            if (errno == EINTR) return;
            throw std::runtime_error("epoll_wait");
        }
        for (int i = 0; i < n; ++i) {
            int fd = events[i].data.fd;
            if (fd == listener_) {
                for (;;) {
                    int c = ::accept4(listener_, nullptr, nullptr,
                                      SOCK_NONBLOCK | SOCK_CLOEXEC);
                    if (c < 0 && errno == EINTR) continue;
                    if (c < 0) break; // EAGAIN normal; other errors log
                    try {
                        conns_.emplace(c, Conn{});
                        interest(c, EPOLLIN | EPOLLRDHUP, EPOLL_CTL_ADD);
                    } catch (...) { conns_.erase(c); ::close(c); throw; }
                }
                continue;
            }
            auto it = conns_.find(fd);
            if (it == conns_.end()) continue;
            bool dead = (events[i].events & (EPOLLERR | EPOLLHUP | EPOLLRDHUP));
            auto& conn = it->second;
            if (!dead && (events[i].events & EPOLLIN)) {
                for (;;) {
                    char b[4096];
                    ssize_t r = ::recv(fd, b, sizeof(b), 0);
                    if (r > 0) {
                        if (conn.pending.size() - conn.sent +
                            static_cast<size_t>(r) > 1024 * 1024) {
                            dead = true; break;
                        }
                        conn.pending.append(b, static_cast<size_t>(r));
                    } else if (r == 0) { dead = true; break; }
                    else if (errno == EINTR) continue;
                    else if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                    else { dead = true; break; }
                }
            }
            if (!dead && !conn.pending.empty()) {
                while (conn.sent < conn.pending.size()) {
                    ssize_t r = ::send(fd, conn.pending.data() + conn.sent,
                                       conn.pending.size() - conn.sent, MSG_NOSIGNAL);
                    if (r > 0) conn.sent += static_cast<size_t>(r);
                    else if (r < 0 && errno == EINTR) continue;
                    else if (r < 0 && (errno == EAGAIN || errno == EWOULDBLOCK))
                        break;
                    else { dead = true; break; }
                }
                if (conn.sent == conn.pending.size()) {
                    conn.pending.clear(); conn.sent = 0;
                }
            }
            if (dead) closeConn(fd);
            else interest(fd, EPOLLIN | EPOLLRDHUP |
                              (!conn.pending.empty() ? EPOLLOUT : 0), EPOLL_CTL_MOD);
        }
    }
};
~~~

**复杂度**：按实际接收/发送字节数线性；缓存总量 O(active connections × 1MiB) 上限。**面试要点**：short write、EPOLLOUT 事件启停；仅用 fd 的 stale-event/reuse 风险（生产使用稳定 token + generation）；read-half-close 之后可选择 flush 而非直接丢包；buffer compact；slow-reader attack；零拷贝 sendmsg/io_uring/kernel bypass；accept 错误分类与 fd exhaustion。此版本单线程，所有操作都在同一事件线程，未做多线程并发安全。

## 23. Distributed Job Scheduler + Retry（P2）

**题目**：多个 worker 竞争领取任务，崩溃后超时重新领取；每个任务有 lease、attempt、fencing token。必须明确：仅靠内存 mutex 不构成分布式容错，生产须由数据库提供 durable atomic compare-and-swap。

~~~cpp
#include <chrono>
#include <cstdint>
#include <mutex>
#include <optional>
#include <string>
#include <unordered_map>

struct JobRecord {
    enum class State { Ready, Leased, Done, Failed };
    std::string id, payload;
    State state = State::Ready;
    uint64_t token = 0;
    unsigned attempts = 0;
    int64_t leaseUntilMs = 0;
};

class InMemoryJobStore { // deterministic test double, NOT distributed storage
    std::mutex m_;
    std::unordered_map<std::string, JobRecord> jobs_;
public:
    void add(JobRecord job) {
        std::lock_guard<std::mutex> lk(m_);
        jobs_.emplace(job.id, std::move(job));
    }
    std::optional<JobRecord> claim(int64_t nowMs, int64_t leaseMs,
                                   unsigned maxAttempts) {
        std::lock_guard<std::mutex> lk(m_);
        for (auto& [id, j] : jobs_) {
            bool ready = j.state == JobRecord::State::Ready;
            bool expired = j.state == JobRecord::State::Leased &&
                           nowMs >= j.leaseUntilMs;
            if (!ready && !expired) continue;
            if (j.attempts >= maxAttempts) {
                j.state = JobRecord::State::Failed; continue;
            }
            j.state = JobRecord::State::Leased;
            j.leaseUntilMs = nowMs + leaseMs;
            ++j.attempts;
            ++j.token; // generation/fencing token
            return j;
        }
        return std::nullopt;
    }
    bool complete(const std::string& id, uint64_t token) {
        std::lock_guard<std::mutex> lk(m_);
        auto it = jobs_.find(id);
        if (it == jobs_.end() ||
            it->second.state != JobRecord::State::Leased ||
            it->second.token != token) return false;
        it->second.state = JobRecord::State::Done;
        return true;
    }
};
~~~

**复杂度**：本测试版 claim O(job count)，complete 平均 O(1)。**面试要点**：数据库事务中实现 claim CAS；lease renewal；fencing 必须由 side effect 接收方校验；exactly-once 通常要转化为 at-least-once + 幂等；时钟来源必须统一（存储服务器时间）；指数退避、DLQ；顺序与公平；任务依赖 DAG；跨机可观测性。代码只是核心状态机，不是分布式完整答案。

## 24. Storage Engine: WAL + In-memory Index（P2）

**题目**：单进程持久 key/value；put/erase 先顺序写 WAL 并 fsync，再变更 in-memory 索引；重启重放 WAL。设 key/value 最大 1 MiB，文件只由本进程访问。

~~~cpp
#include <cstdint>
#include <cerrno>
#include <fcntl.h>
#include <unistd.h>
#include <stdexcept>
#include <string>
#include <unordered_map>
#include <optional>

class WalKv {
    struct Header { uint32_t keySize, valueSize, op; }; // same ABI only
    int fd_;
    off_t end_ = 0;
    bool poisoned_ = false;
    std::unordered_map<std::string, std::string> map_;
    static bool readAt(int fd, off_t offset, void* p, size_t n) {
        auto* b = static_cast<char*>(p);
        while (n) {
            ssize_t r = ::pread(fd, b, n, offset);
            if (r < 0 && errno == EINTR) continue;
            if (r <= 0) return false;
            b += r; n -= static_cast<size_t>(r); offset += r;
        }
        return true;
    }
    static void writeAt(int fd, off_t offset, const void* p, size_t n) {
        auto* b = static_cast<const char*>(p);
        while (n) {
            ssize_t w = ::pwrite(fd, b, n, offset);
            if (w < 0 && errno == EINTR) continue;
            if (w <= 0) throw std::runtime_error("write WAL");
            b += w; n -= static_cast<size_t>(w); offset += w;
        }
    }
    void replay() {
        for (;;) {
            Header h{};
            if (!readAt(fd_, end_, &h, sizeof(h))) break;
            if (h.keySize > (1u<<20) || h.valueSize > (1u<<20) ||
                (h.op != 1 && h.op != 2)) break;
            std::string key(h.keySize, '\0'), value(h.valueSize, '\0');
            if (!readAt(fd_, end_ + sizeof(h), key.data(), key.size()) ||
                !readAt(fd_, end_ + sizeof(h) + key.size(),
                        value.data(), value.size())) break;
            if (h.op == 1) map_[key] = std::move(value);
            else map_.erase(key);
            end_ += sizeof(h) + h.keySize + h.valueSize;
        }
        if (::ftruncate(fd_, end_) != 0)
            throw std::runtime_error("truncate WAL tail");
    }
    void append(uint32_t op, const std::string& key,
                const std::string& value) {
        if (poisoned_) throw std::runtime_error("poisoned WAL");
        if (key.size() > (1u<<20) || value.size() > (1u<<20))
            throw std::invalid_argument("record too large");
        Header h{static_cast<uint32_t>(key.size()),
                 static_cast<uint32_t>(value.size()), op};
        try {
            writeAt(fd_, end_, &h, sizeof(h));
            writeAt(fd_, end_ + sizeof(h), key.data(), key.size());
            writeAt(fd_, end_ + sizeof(h) + key.size(), value.data(), value.size());
            if (::fsync(fd_) != 0) throw std::runtime_error("fsync");
            end_ += sizeof(h) + key.size() + value.size();
        } catch (...) { poisoned_ = true; throw; }
    }
public:
    explicit WalKv(const char* path) : fd_(::open(path, O_CREAT | O_RDWR | O_CLOEXEC, 0600)) {
        if (fd_ < 0) throw std::runtime_error("open WAL");
        try { replay(); }
        catch (...) { ::close(fd_); throw; }
    }
    ~WalKv() { ::close(fd_); }
    void put(std::string key, std::string value) {
        // Preallocate index work first if strong no-loss guarantees are required.
        append(1, key, value);
        map_[std::move(key)] = std::move(value);
    }
    void erase(const std::string& key) {
        append(2, key, "");
        map_.erase(key);
    }
    std::optional<std::string> get(const std::string& key) const {
        auto it = map_.find(key);
        if (it == map_.end()) return std::nullopt;
        return it->second;
    }
};
~~~

**复杂度**：get 期望 O(1)，put O(record length + sync latency)，恢复 O(WAL size)；磁盘无限增长。**面试要点**：这个版本不支持并发；不能检测完整但被位翻转损坏的尾记录，生产必须有 CRC/长度框架/version；Header native endian/ABI 不适合跨版本；文件创建后的目录 fsync；index 更新 OOM 可能出现“已写 WAL 但当前内存未更新”，应做预分配或进入 fail-stop/recover；checkpoint/compaction、LSM/B+tree、group commit、write amplification。

## 25. CPU Resource Scheduler with Priorities & Isolation（P2）

**题目**：给不同负载组配置权重和队列长度上限，设计简单 weighted round-robin 决策器。真实 CPU 隔离由 cgroups/cpuset/affinity 执行，本题只实现 scheduling policy。

~~~cpp
#include <cstddef>
#include <deque>
#include <optional>
#include <vector>
#include <stdexcept>

struct CpuJob { uint64_t id; int estimatedCost; };
class WeightedScheduler {
    struct Group {
        unsigned weight, credits;
        size_t maxQueue;
        std::deque<CpuJob> jobs;
    };
    std::vector<Group> groups_;
    size_t cursor_ = 0;
public:
    void addGroup(unsigned weight, size_t maxQueued) {
        if (!weight || !maxQueued) throw std::invalid_argument("group");
        groups_.push_back({weight, weight, maxQueued, {}});
    }
    bool enqueue(size_t group, CpuJob j) {
        if (group >= groups_.size()) return false;
        auto& q = groups_[group];
        if (q.jobs.size() >= q.maxQueue) return false;
        q.jobs.push_back(j);
        return true;
    }
    std::optional<CpuJob> next() {
        if (groups_.empty()) return std::nullopt;
        for (size_t scans = 0; scans < groups_.size(); ++scans) {
            auto& g = groups_[cursor_];
            if (!g.jobs.empty() && g.credits) {
                CpuJob j = g.jobs.front(); g.jobs.pop_front();
                if (--g.credits == 0) {
                    g.credits = g.weight;
                    cursor_ = (cursor_ + 1) % groups_.size();
                }
                return j;
            }
            g.credits = g.weight;
            cursor_ = (cursor_ + 1) % groups_.size();
        }
        return std::nullopt;
    }
};
~~~

**复杂度**：enqueue O(1)，next 最坏 O(groups)；空间 O(sum queue capacities)。**面试要点**：权重只控制任务数而非实际 CPU 时间，不能保证 runtime fairness；非抢占任务需要 time slicing；priority 与 starvation、priority inversion；SCHED_FIFO/SCHED_RR、cgroups v2 cpu.max/cpu.weight、cpuset.cpus；NUMA/cache affinity；低延迟线程隔离与吞吐型批处理混部；热迁移/过载恢复。

# 系统级 C++ 设计面试题 06：HFT / Trading 专项（26–30）

> 新增五题，针对 Market Data、OMS、Execution、Connectivity 与低延迟平台。代码使用 C++17；每题为清晰的面试最小实现，真实交易系统必须补充交易所方言、持久化、风控与异常恢复。本系列与仓库已有《订单状态机工程设计》等文档互补。

## 26. Order State Machine: Fills, Cancel & Dedup（P0）

**题目**：实现单订单状态变更：New Ack、Fill、Cancel Request、Cancel Ack、Cancel Reject。Fill 按 ExecID 去重；PendingCancel 期间的 Fill 必须正常累计；CancelAck 后可能仍收到迟到 Fill。订单固定原始数量，成交量不可越界。外部 Event Buffer 已校验 OrderID 与请求关联。

~~~cpp
#include <cstdint>
#include <stdexcept>
#include <string>
#include <unordered_set>

class OrderState {
public:
    enum class Status { PendingNew, Working, PendingCancel, Canceled, Filled };
private:
    int64_t total_, filled_ = 0;
    bool newAck_ = false, cancelPending_ = false, cancelAck_ = false;
    std::unordered_set<std::string> seenExecIds_;
public:
    explicit OrderState(int64_t qty) : total_(qty) {
        if (qty <= 0) throw std::invalid_argument("quantity");
    }
    Status status() const {
        if (filled_ == total_) return Status::Filled;
        if (cancelAck_) return Status::Canceled;
        if (cancelPending_) return Status::PendingCancel;
        return newAck_ ? Status::Working : Status::PendingNew;
    }
    void onNewAck() { newAck_ = true; }
    void requestCancel() {
        if (status() == Status::Working || status() == Status::PendingCancel)
            cancelPending_ = true;
        else throw std::logic_error("cancel not allowed");
    }
    void onCancelAck() { cancelPending_ = false; cancelAck_ = true; }
    void onCancelReject() { cancelPending_ = false; /* retain fills */ }
    bool onFill(const std::string& execId, int64_t qty) {
        if (seenExecIds_.count(execId)) return false;
        if (qty <= 0 || qty > total_ - filled_)
            throw std::invalid_argument("invalid fill quantity");
        seenExecIds_.insert(execId); // insertion before count, so OOM does not alter qty
        filled_ += qty;
        return true;
    }
    int64_t filled() const { return filled_; }
    int64_t leaves() const {
        return cancelAck_ ? 0 : total_ - filled_;
    }
};
~~~

**复杂度**：每个事件平均 O(1)；内存 O(distinct ExecIDs)。**面试要点**：状态不应作为所有事实的唯一来源；PendingCancel 与 PartialFill 是两个维度；late fill 不能静默丢弃；CancelReject 与 NewReject 不相同；FIX 39 OrdStatus vs 150 ExecType；ExecID 去重作用域；Exec correction/bust 并不在本题范围；CancelAck 后 late Fill 是否覆盖终态按 venue 规则定义。生产版须先 journal 再应用，保证 durable idempotency，并记录请求 ID、交易所 ID、发生时间。

## 27. Multi-Source Market Data Aggregator + Expiry（P0）

**题目**：多个 venue/source 各给 best bid/ask；每源的更新 seq 严格递增，若出现 gap 则不再信任该源，等待 snapshot；当心跳超时或报价 TTL 超时时剔除该源；聚合出 best bid 与 ask（可来自不同源）。price、qty 使用 int64_t。

~~~cpp
#include <chrono>
#include <cstdint>
#include <map>
#include <optional>
#include <stdexcept>

class BestQuoteAggregator {
public:
    using Clock = std::chrono::steady_clock;
    struct Quote {
        int64_t bid = 0, bidQty = 0, ask = 0, askQty = 0;
        uint64_t seq = 0;
        Clock::time_point received{};
        bool stale = true;
    };
    struct Best {
        std::optional<std::pair<int64_t, int>> bid; // price, sourceId
        std::optional<std::pair<int64_t, int>> ask;
    };
private:
    std::map<int, Quote> sources_;
public:
    bool delta(int sourceId, Quote q) {
        auto it = sources_.find(sourceId);
        if (it == sources_.end() || it->second.stale) return false;
        auto& old = it->second;
        if (q.seq <= old.seq) return false; // duplicate/old
        if (q.seq != old.seq + 1) {
            old.stale = true; // signal snapshot request to feed handler
            return false;
        }
        q.stale = false;
        old = q;
        return true;
    }
    void snapshot(int sourceId, Quote q) {
        if (q.bidQty < 0 || q.askQty < 0)
            throw std::invalid_argument("negative quantity");
        q.stale = false;
        sources_[sourceId] = q;
    }
    void markStale(int sourceId) { sources_[sourceId].stale = true; }
    Best best(Clock::time_point now, Clock::duration ttl) const {
        Best out;
        for (auto& [source, q] : sources_) {
            if (q.stale || now < q.received || now - q.received >= ttl) continue;
            if (q.bidQty > 0 && (!out.bid || q.bid > out.bid->first))
                out.bid = {{q.bid, source}};
            if (q.askQty > 0 && (!out.ask || q.ask < out.ask->first))
                out.ask = {{q.ask, source}};
        }
        return out;
    }
};
~~~

**复杂度**：delta O(log sources)，best O(sources)；每源固定 O(1) 数据。**面试要点**：严格序列号更新 vs heartbeat（heartbeat 可能单独提供 liveness）；本例仅 BBO，不支持多档 depth 和 source 删除；network backlog 会让 TTL 基于 receive time 显得“新”，必要时检查 exchange/source timestamp；stale 与 delete 业务含义；source stale 后聚合 cache 必须失效；跨 venue top-of-book 可 crossed，是否允许由策略决定；完整实现应允许 snapshot seq 与 buffered deltas 拼接。

## 28. Price–Time Priority Order Book / Matching（P0）

**题目**：实现单品种限价单撮合：价格优先，同价 FIFO；add 自动执行 crossing，未成交剩余挂单；cancel(id) 可以撤掉 resting order。整数价格、数量，单线程 owner。返回本次撮合明细。

~~~cpp
#include <cstdint>
#include <list>
#include <map>
#include <unordered_map>
#include <vector>
#include <stdexcept>

class SimpleMatchBook {
    using Id = uint64_t;
    using Price = int64_t;
    struct Order { Id id; Price px; int64_t qty; };
    using Queue = std::list<Order>;
    using Bids = std::map<Price, Queue, std::greater<Price>>;
    using Asks = std::map<Price, Queue>;
    struct Ref { bool bid; Price px; Queue::iterator it; };
    Bids bids_;
    Asks asks_;
    std::unordered_map<Id, Ref> byId_;
public:
    struct Fill { Id maker, taker; Price px; int64_t qty; };
    bool cancel(Id id) {
        auto it = byId_.find(id);
        if (it == byId_.end()) return false;
        auto ref = it->second;
        if (ref.bid) {
            auto level = bids_.find(ref.px);
            level->second.erase(ref.it);
            if (level->second.empty()) bids_.erase(level);
        } else {
            auto level = asks_.find(ref.px);
            level->second.erase(ref.it);
            if (level->second.empty()) asks_.erase(level);
        }
        byId_.erase(it);
        return true;
    }
    std::vector<Fill> add(Id id, bool isBuy, Price price, int64_t qty) {
        if (qty <= 0 || byId_.count(id))
            throw std::invalid_argument("bad order");
        std::vector<Fill> fills;
        if (isBuy) {
            while (qty > 0 && !asks_.empty() && asks_.begin()->first <= price) {
                auto level = asks_.begin();
                auto& maker = level->second.front();
                int64_t q = std::min(qty, maker.qty);
                fills.push_back({maker.id, id, maker.px, q});
                maker.qty -= q; qty -= q;
                if (maker.qty == 0) {
                    byId_.erase(maker.id);
                    level->second.pop_front();
                    if (level->second.empty()) asks_.erase(level);
                }
            }
            if (qty) {
                auto& level = bids_[price];
                level.push_back({id, price, qty});
                byId_.emplace(id, Ref{true, price, std::prev(level.end())});
            }
        } else {
            while (qty > 0 && !bids_.empty() && bids_.begin()->first >= price) {
                auto level = bids_.begin();
                auto& maker = level->second.front();
                int64_t q = std::min(qty, maker.qty);
                fills.push_back({maker.id, id, maker.px, q});
                maker.qty -= q; qty -= q;
                if (maker.qty == 0) {
                    byId_.erase(maker.id);
                    level->second.pop_front();
                    if (level->second.empty()) bids_.erase(level);
                }
            }
            if (qty) {
                auto& level = asks_[price];
                level.push_back({id, price, qty});
                byId_.emplace(id, Ref{false, price, std::prev(level.end())});
            }
        }
        return fills;
    }
};
~~~

**复杂度**：add O(log price levels + matched resting orders)；cancel 预期 O(1) hash + O(log levels) map 查找。**面试要点**：同价 FIFO 和 list iterator 稳定性；maker price execution；Duplicate ID 只检查当前 resting order（已成交 ID 需外部全局去重）；partial fill；stop/iceberg 不在题目范围；异常在撮合循环中抛出可能发生部分 mutation，生产版需 transactional event/journal 或预分配；高性能可用 intrusive list + pool + price index，避免动态分配。

## 29. Bounded Lock-Free MPSC Ring Buffer（P1）

**题目**：多个 producer，一个 consumer；固定容量为 2 的幂。生产者 CAS 预定 slot，slot sequence 发布消息，消费者独占头指针；满时立即返回 false。T 必须 noexcept move construct/destruct，避免 reservation 后抛异常导致 slot 永久卡住。

~~~cpp
#include <atomic>
#include <cstddef>
#include <cstdint>
#include <memory>
#include <new>
#include <optional>
#include <type_traits>
#include <utility>

template<class T, size_t Capacity>
class MpscRing {
    static_assert(Capacity >= 2 && (Capacity & (Capacity - 1)) == 0);
    static_assert(std::is_nothrow_move_constructible_v<T>);
    static_assert(std::is_nothrow_destructible_v<T>);
    struct Slot {
        std::atomic<size_t> seq{0};
        std::aligned_storage_t<sizeof(T), alignof(T)> storage;
    };
    std::unique_ptr<Slot[]> slots_{new Slot[Capacity]};
    alignas(64) std::atomic<size_t> tail_{0};
    alignas(64) size_t head_ = 0; // consumer only
public:
    MpscRing() {
        for (size_t i = 0; i < Capacity; ++i)
            slots_[i].seq.store(i, std::memory_order_relaxed);
    }
    bool try_push(T value) {
        size_t pos = tail_.load(std::memory_order_relaxed);
        Slot* s;
        for (;;) {
            s = &slots_[pos & (Capacity - 1)];
            size_t seq = s->seq.load(std::memory_order_acquire);
            auto diff = static_cast<std::intptr_t>(seq - pos);
            if (diff == 0) {
                if (tail_.compare_exchange_weak(pos, pos + 1,
                       std::memory_order_relaxed)) break;
            } else if (diff < 0) return false;
            else pos = tail_.load(std::memory_order_relaxed);
        }
        new (&s->storage) T(std::move(value));
        s->seq.store(pos + 1, std::memory_order_release);
        return true;
    }
    std::optional<T> try_pop() {
        auto& s = slots_[head_ & (Capacity - 1)];
        size_t seq = s.seq.load(std::memory_order_acquire);
        if (seq != head_ + 1) return std::nullopt;
        auto* p = std::launder(reinterpret_cast<T*>(&s.storage));
        std::optional<T> out(std::move(*p));
        p->~T();
        s.seq.store(head_ + Capacity, std::memory_order_release);
        ++head_;
        return out;
    }
    ~MpscRing() {
        // Preconditions: all producer/consumer threads have stopped.
        while (try_pop()) {}
    }
};
~~~

**复杂度**：平均 O(1) 尝试；空间 O(Capacity)；存在 CAS 自旋，故操作并非 wait-free。**面试要点**：head/tail ownership、sequence 区分轮次与满空、publish release / consume acquire、slot reuse 同步、producer 在保留 slot 后挂起会阻止消费者进展（不是 lock-free overall progress 的无条件保证）；64-bit wrap-around 假设；false sharing；批处理；在确定性低延迟系统中优先选 SPSC partition/owner 而不是无条件使用 MPSC。

## 30. Snapshot + Delta Sequencing & Recovery（P0）

**题目**：market data 有 snapshot(seq, full book) 和 delta(seq, px, qty)。只按连续 seq 应用 delta；出现 gap 时暂停并请求 snapshot，暂存后续消息；snapshot 后丢弃老 delta，按顺序 replay 可衔接部分。设 qty=0 表示删除价位、单流单 symbol。

~~~cpp
#include <cstdint>
#include <map>
#include <stdexcept>
#include <utility>

class SequencedBook {
public:
    using Price = int64_t;
    using Qty = int64_t;
    struct Delta { uint64_t seq; Price price; Qty qty; };
    enum class Result { Applied, Duplicate, NeedSnapshot, Buffered };
private:
    uint64_t lastSeq_ = 0;
    bool ready_ = false;
    std::map<Price, Qty> levels_;
    std::map<uint64_t, Delta> pending_;
    static constexpr size_t MAX_BUFFER = 4096;

    void apply(const Delta& d) {
        if (d.qty < 0) throw std::invalid_argument("negative qty");
        if (d.qty == 0) levels_.erase(d.price);
        else levels_[d.price] = d.qty;
    }
    void replayContiguous() {
        for (;;) {
            auto it = pending_.find(lastSeq_ + 1);
            if (it == pending_.end()) return;
            apply(it->second);
            ++lastSeq_;
            pending_.erase(it);
        }
    }
public:
    Result onDelta(Delta d) {
        if (d.qty < 0) throw std::invalid_argument("qty");
        if (ready_ && d.seq <= lastSeq_) return Result::Duplicate;
        if (pending_.size() >= MAX_BUFFER) {
            pending_.clear(); ready_ = false;
            return Result::NeedSnapshot;
        }
        pending_.emplace(d.seq, d);
        if (!ready_) return Result::NeedSnapshot;
        if (d.seq != lastSeq_ + 1) {
            ready_ = false;  // conservative: freeze until next snapshot
            return Result::NeedSnapshot;
        }
        replayContiguous();
        return Result::Applied;
    }
    bool onSnapshot(uint64_t seq, std::map<Price, Qty> fresh) {
        for (auto& [px, qty] : fresh)
            if (qty <= 0) throw std::invalid_argument("snapshot qty");
        levels_.swap(fresh);
        lastSeq_ = seq;
        for (auto it = pending_.begin(); it != pending_.end(); )
            if (it->first <= seq) it = pending_.erase(it);
            else ++it;
        ready_ = true;
        replayContiguous();
        if (!pending_.empty() && pending_.begin()->first != lastSeq_ + 1) {
            ready_ = false;
        }
        return ready_;
    }
    bool isReady() const { return ready_; }
    uint64_t lastSeq() const { return lastSeq_; }
    const std::map<Price, Qty>& book() const { return levels_; }
};
~~~

**复杂度**：每个 delta O(log buffered + log price levels)；snapshot O(full depth + buffered replay)。**面试要点**：snapshot 的 seq 边界，snapshot-before/after delta 的语义必须由 feed 协议定义；seq wrap-around/stream reset；一旦 gap，缓存的后续消息是否足够恢复取决于 snapshot 与 replay 来源；不能静默直接跳过缺失增量；心跳超时与 seq-gap 不同；ready=false 时禁止交易；恢复成功后原子替换对外可见 book；buffer 上限与快照反复失败策略。上述示例原子快照发布未实现，且 onSnapshot 对异常仅提供基本保证。

## HFT 专项的共同工程要点

- **单写者与可恢复输入**：保持每个 book/order 的明确 owner；接收、journal、状态提交、outbox 的一致性边界要写清。
- **Trading correctness 优先于微优化**：duplicate fill、seq gap、cancel/fill race、超时未知结果都不能假设是普通失败。
- **性能**：对象池/boost intrusive、preallocation、NUMA/affinity、cache alignment、bounded queues、Aeron/共享内存 IPC。
- **测试**：乱序、重复、部分执行、gap、snapshot 重放、timer stall、backpressure、进程重启、随机事件 property test。
