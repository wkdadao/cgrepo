# 排列与组合中的去重原理总结

## 1. 核心思想

排列（Permutation）和组合（Combination）中的“去重”，本质上都不是：

> 不允许出现相同的值。

而是：

> **人为规定一种唯一的搜索顺序，使所有等价搜索路径只保留一个 canonical representation，从而剪掉重复分支。**

通常第一步都是先排序：

```cpp
std::sort(nums.begin(), nums.end());
```

排序以后，相同值相邻，才能方便判断：

```text
nums[i] == nums[i - 1]
```

---

# 2. 排列中的去重

## 2.1 重复是怎么产生的

例如：

```text
nums = [1a, 1b, 2]
```

其中：

```text
1a == 1b
```

值相同，只是下标不同。

普通 permutation 会把它们当成不同元素，因此同时搜索：

```text
1a -> 1b -> 2
1b -> 1a -> 2
```

最终得到的值序列却完全相同：

```text
[1, 1, 2]
[1, 1, 2]
```

重复的根源是：

> **相同值元素的“身份交换”产生了不同搜索路径，但最终结果相同。**

---

## 2.2 去重原则：给相同元素建立固定的使用先后关系

我们人为规定：

```text
1a before 1b before 1c ...
```

也就是说：

> 如果前一个相同元素还没有被使用，那么当前元素不能抢在它前面被使用。

标准条件：

```cpp
if (i > 0 &&
    nums[i] == nums[i - 1] &&
    !used[i - 1])
{
    continue;
}
```

核心是：

```cpp
!used[i - 1]
```

含义：

> 前一个相同元素当前不在 path 中，因此当前元素不能先被使用。

---

## 2.3 为什么允许 1a -> 1b

假设已经选择：

```text
path = [1a]
```

现在准备选择 `1b`：

```cpp
used[1a] == true
```

所以：

```cpp
!used[i - 1] == false
```

不会被剪枝。

因此：

```text
1a -> 1b -> 2
```

是合法的。

但是：

```text
1b -> 1a -> 2
```

会在第一步就被剪掉，因为尝试 `1b` 时：

```cpp
used[1a] == false
```

这就是排列去重最核心的思想：

> **对相同元素建立一个固定的“被使用先后关系”，从而消除由于交换相同元素身份产生的重复搜索分支。**

# 3. 排列去重模板

以 LeetCode 47 — Permutations II 为例：

```cpp
class Solution
{
public:
    std::vector<std::vector<int>> permuteUnique(std::vector<int>& nums)
    {
        std::sort(nums.begin(), nums.end());

        std::vector<std::vector<int>> ans;
        std::vector<int> path;
        std::vector<bool> used(nums.size(), false);

        dfs(nums, used, path, ans);

        return ans;
    }

private:
    void dfs(const std::vector<int>& nums,
             std::vector<bool>& used,
             std::vector<int>& path,
             std::vector<std::vector<int>>& ans)
    {
        if (path.size() == nums.size())
        {
            ans.push_back(path);
            return;
        }

        for (int i = 0; i < static_cast<int>(nums.size()); ++i)
        {
            if (used[i])
                continue;

            // 排列去重：
            // 相同值元素必须按照固定的下标顺序被使用。
            if (i > 0 &&
                nums[i] == nums[i - 1] &&
                !used[i - 1])
            {
                continue;
            }

            used[i] = true;
            path.push_back(nums[i]);

            dfs(nums, used, path, ans);

            path.pop_back();
            used[i] = false;
        }
    }
};
```

# 4. 组合中的去重

## 4.1 组合本身已经消除了“顺序重复”

组合使用：

```cpp
dfs(i + 1, ...)
```

也就是每次只能向右选择。

因此：

```text
1 -> 2
```

存在，但：

```text
2 -> 1
```

不会被搜索。

所以组合天然已经消除了：

```text
[1, 2]
[2, 1]
```

这种“顺序不同、集合相同”的重复。

---

## 4.2 组合剩下的重复来自哪里

仍然考虑：

```text
nums = [1a, 1b, 2]
```

在同一层搜索时，如果同时允许：

```text
选 1a
选 1b
```

那么会出现：

```text
1a -> 2
1b -> 2
```

最终都是：

```text
[1, 2]
```

这两棵子树实际上是等价的。

因此组合去重的原则是：

> **同一递归层，只允许相同值中的第一个元素作为分支起点。**

标准条件：

```cpp
if (i > start &&
    nums[i] == nums[i - 1])
{
    continue;
}
```

---

# 5. 为什么条件是 i > start

假设当前这一层：

```text
start = 0

nums:
1a   1b   1c   2
 ^    ^    ^
 |    |    |
允许  跳过  跳过
```

第一个 `1a`：

```cpp
i == start
```

必须允许。

后面的：

```text
1b
1c
```

满足：

```cpp
i > start &&
nums[i] == nums[i - 1]
```

所以跳过。

于是当前这一层：

> 相同值只由最左边的元素代表。

---

# 6. 树层去重，树枝不去重

这是组合去重最重要的理解。

例如：

```text
nums = [1a, 1b, 2]
```

搜索树：

```text
                  []
           /       |       \
         1a       1b        2
        /  \
      1b    2
```

根节点这一层：

```text
1a
1b
```

属于同一递归层。

因为值相同，所以：

```text
1a -> 保留
1b -> 剪掉
```

但是：

```text
1a
 |
1b
```

属于不同递归层，即同一树枝。

这是合法的，因为它代表：

```text
[1, 1]
```

因此组合去重可以浓缩成一句话：

> **树层去重，树枝不去重。**

也就是说：

- 同一层，相同值只让第一个元素开分支；
- 不同层，仍然可以继续选择相同值。

# 7. 组合 / 子集去重模板

例如 LeetCode 40 — Combination Sum II：

```cpp
class Solution
{
public:
    std::vector<std::vector<int>> combinationSum2(
        std::vector<int>& candidates,
        int target)
    {
        std::sort(candidates.begin(), candidates.end());

        std::vector<std::vector<int>> ans;
        std::vector<int> path;

        dfs(candidates, 0, target, path, ans);

        return ans;
    }

private:
    void dfs(const std::vector<int>& nums,
             int start,
             int remain,
             std::vector<int>& path,
             std::vector<std::vector<int>>& ans)
    {
        if (remain == 0)
        {
            ans.push_back(path);
            return;
        }

        for (int i = start; i < static_cast<int>(nums.size()); ++i)
        {
            // 同一递归层，相同值只允许第一个元素作为分支起点。
            if (i > start &&
                nums[i] == nums[i - 1])
            {
                continue;
            }

            if (nums[i] > remain)
                break;

            path.push_back(nums[i]);

            // 每个元素只能使用一次。
            dfs(nums,
                i + 1,
                remain - nums[i],
                path,
                ans);

            path.pop_back();
        }
    }
};
```

同样的去重规则也适用于：

- LeetCode 90 — Subsets II
- 其他输入中存在重复值的 Combination / Subset 类问题

# 8. 为什么组合通常不需要 used[]

组合的基本结构已经是：

```cpp
for (int i = start; i < n; ++i)
{
    path.push_back(nums[i]);

    dfs(i + 1, ...);

    path.pop_back();
}
```

`start` 已经规定：

> 后续只能从当前位置右边继续选择。

因此搜索天然具有一个固定的 index 顺序：

```text
i1 < i2 < i3 < ...
```

不会出现：

```text
1 -> 2
2 -> 1
```

这种排列型重复。

所以组合不需要 `used[]` 来记录“哪些元素已经使用”。

它剩下唯一需要处理的，是：

> **同一层多个相同值产生等价子树。**

因此直接使用：

```cpp
i > start && nums[i] == nums[i - 1]
```

即可。

---

# 9. 为什么排列不能直接使用组合的去重规则

Permutation 每一层都需要重新扫描全部元素：

```cpp
for (int i = 0; i < n; ++i)
```

因为任何一个尚未使用的元素都可能成为下一位。

Permutation 没有：

```cpp
start
```

这种“只能向右选择”的约束。

因此必须通过：

```cpp
used[]
```

判断：

> 前一个相同元素是否已经出现在当前搜索路径中。

所以排列的规则必须写成：

```cpp
nums[i] == nums[i - 1] &&
!used[i - 1]
```

而组合则可以直接根据当前层的起点：

```cpp
i > start
```

判断是否属于“同层重复”。

---

# 10. 排列 vs 组合去重对比

| 对比 | 排列 Permutation | 组合 / 子集 Combination / Subset |
|---|---|---|
| 顺序是否重要 | 是 | 否 |
| 基本状态 | `used[]` | `start` |
| 重复来源 | 相同元素交换身份 | 同层相同值产生等价子树 |
| 去重原则 | 相同元素建立固定使用顺序 | 同层相同值只让第一个开分支 |
| 判断依据 | 前一个相同元素是否已在 path | 当前元素是否为本层第一个相同值 |
| 典型条件 | `!used[i - 1]` | `i > start` |
| 代表题目 | LC 47 | LC 40 / 90 |

# 11. 两个最重要的模板条件

## 11.1 排列去重

```cpp
std::sort(nums.begin(), nums.end());

if (used[i])
    continue;

if (i > 0 &&
    nums[i] == nums[i - 1] &&
    !used[i - 1])
{
    continue;
}
```

记忆方式：

> **前一个相同元素还没用，我就不能抢在它前面用。**

本质：

> **对相同元素建立固定的被使用先后关系。**

## 11.2 组合 / 子集去重

std::sort(nums.begin(), nums.end());

# 12. 一个统一的理解：Canonical Representation

排列和组合虽然具体规则不同，但背后的思想完全一致。

存在多个不同搜索路径：

```text
Path A
Path B
Path C
```

如果它们最终代表同一个答案，那么我们人为定义一种规则，只允许其中一种：

```text
Canonical Path
```

其他路径全部剪掉。

因此：

```text
去重 != 不允许重复值
```

真正的含义是：

```text
去重
=
给等价搜索路径规定一个唯一的 canonical representation
=
只搜索其中一种
```

对于排列：

```text
Canonical Rule:
相同元素按照固定身份顺序被使用
```

对于组合：

```text
Canonical Rule:
同一递归层，相同值只允许最左边元素代表该选择
```

# 13. 最终总结

可以直接记住下面两句话。

### 排列

> **对相同元素建立一个固定的“被使用先后关系”，从而消除由于交换相同元素身份产生的重复搜索分支。**

规则：

```cpp
if (i > 0 &&
    nums[i] == nums[i - 1] &&
    !used[i - 1])
{
    continue;
}
```

---

### 组合 / 子集

> **同一递归层只允许相同值的第一个元素作为分支起点。**

规则：

```cpp
if (i > start &&
    nums[i] == nums[i - 1])
{
    continue;
}
```

进一步压缩：

```text
Permutation:
    固定相同元素的使用顺序
    -> !used[i - 1]

Combination / Subset:
    同层相同值只取第一个
    -> i > start
```

这是 LC 47、LC 40、LC 90 等题目中去重逻辑的统一基础。
